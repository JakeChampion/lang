Process and cgroup metrics come from Linux procfs and cgroup files. A dash means the host does not expose that value. Arena size and allocation totals are not current live heap size. Query strings and request bodies never appear in this public request log.

How it works

One-second server-sent events carry real process samples. OS reads share a short cache across viewers. RSS measures resident physical pages. Virtual size includes reserved address space. The runtime allocator can reuse freed blocks within its arena. Handler timing ends when the response is built and excludes the lifetime of an event stream or WebSocket. HTTP polling is a fallback when streaming is unavailable.
