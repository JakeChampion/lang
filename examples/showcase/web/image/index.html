How it works

The pipeline comes from the fern-image packages: pixels checks each layout, resize scales with a bilinear or nearest-neighbor filter, color converts to grayscale in linear light, and the PNG codec encodes the result. The browser decodes your own image to RGBA pixels, and Fern does the rest in WebAssembly. For a generated image, the native server runs the same stages, and the two PNG files must be identical.
