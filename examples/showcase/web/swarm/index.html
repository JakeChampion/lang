The field follows a procedural flow, with no saved simulation history. Pause stops its animation loop. Audio starts only after your click. No microphone access.

How it works

The same literate Fern module compiles to native code or a Wasm core module. Two scalar exports compute particle coordinates and PCM audio samples. Calls allocate no heap memory. JavaScript reuses one graphics buffer. WebGL draws the points, and a worker prepares audio through the same Fern kernel. The server delivers the files and receives no particle updates.
