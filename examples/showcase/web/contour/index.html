Drag or use ← → to steer. ↑ ↓ changes altitude. Space pauses when the canvas is focused. On touch screens, drag to turn and use the sliders to fly.

How it works

Fern WebAssembly generates a heightfield with three layers of smooth noise. The browser walks from near to far, drawing only the newly visible edge of each ridge. A low-resolution canvas keeps the pixels crisp.

Inspired by 0xC0DE’s two-colour terrain demo ↗. This is an independent recreation of the visual effect.
