How it works

The server and this page generate the same access log from a seed. Fern encodes it with the standard library's gzip, Brotli, and zstd, then decodes the result and compares checksums. Your browser's CompressionStream encodes the same bytes with its native gzip. Where your browser has a decoder for a format, it also decodes Fern's output, which shows that Fern writes standard streams.
