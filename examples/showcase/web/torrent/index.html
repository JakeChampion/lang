How it works

The page splits the file into pieces and hashes each piece with SHA-1 in Fern WebAssembly. The info dictionary of the pieces gives the info hash, which names the swarm. The page registers the hash with the native Fern tracker and announces itself. A downloader with only the info hash asks a peer for the info dictionary with the metadata extension, checks it against the hash, and then requests the pieces. Each piece must match its SHA-1 hash before the page keeps it.

The tracker accepts only swarms that this page registered, for one hour, with at most 12 peers and 64 MiB. It sees each peer's network address and the info hash. The file bytes go directly between browsers. A WebTorrent client can open the magnet link while the swarm lives.
