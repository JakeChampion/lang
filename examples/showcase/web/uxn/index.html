        What is running here?
        

          The Fern kernel implements every Uxn opcode, including short, return,
          and keep modes, immediate jumps, circular stacks, and wrapped memory.
          The Uxntal assembler also runs in Fern. JavaScript supplies browser
          events and displays the framebuffer, console, and machine state.
        

        

          Supported devices: System palette and stack indexes, Console
          input/output, Screen pixels and 1bpp/2bpp sprites, Controller, Mouse,
          and Datetime. Screen dimensions are capped at 512 × 512. Audio, files,
          subprocesses, and memory expansion banks are unavailable. ROMs using
          those devices may not work; attempted writes appear above.
        

        

          The assembler supports labels, child labels, literals, padding,
          address runes, immediate calls/jumps, nested anonymous labels,
          comments, ASCII strings, and macros. It does not support includes or
          multi-bank ROMs. ROMs and source stay in this browser. Execution runs
          in bounded slices; pause and hidden tabs stop scheduling.
          Reduced-motion starts paused.
