Use ↑↓ or WS. On a touch screen, drag your paddle on the court.

How it works

The browser sends paddle targets through a WebSocket. Fern limits movement, advances the ball, checks collisions, and returns the shared game state. The browser predicts your paddle immediately and reconciles each reply. Inputs never wait for a round trip. Two players use the same room. A quiet room does no simulation work. Rooms are held in this server process and reset on restart.
