The fastest JSON parsers, such as simdjson, use SIMD instructions to find structure 32 or 64 bytes at a time. Fern's parser is scalar today. A SIMD kernel is the plan (#12105). This page measures the parser as it is.

How it works

A deterministic generator in Fern produces the document from a seed and a size. The native server and the Wasm kernel compile the same module, so both produce identical bytes, and a checksum confirms it. The tree parser builds a value for each element. The tape parser records each element as two 64-bit words. Each engine parses the document several times and reports the average. Every engine must count the same values.
