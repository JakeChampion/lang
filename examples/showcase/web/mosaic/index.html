This room is shared by everyone with its link. The last write wins. Boards live in this server process and reset on restart.

How Fern makes this work

A brushstroke is a bounded JSON POST. Fern validates every pixel, updates the board, and records a revision. An event stream carries changes to other clients. Last-Event-ID resumes recent history after a reconnect. Older clients receive a full snapshot. PNG export uses Fern's own encoder.
