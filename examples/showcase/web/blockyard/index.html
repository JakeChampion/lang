How Fern runs this world

The native server validates movement and block edits. A browser worker uses Fern Wasm to generate nearby terrain. It combines exposed faces into larger rectangles before WebGL draws them.

Worlds support up to 512 participants. The server sends nearby players and block changes. It shares each movement snapshot with everyone in the same area.

A persistent data volume enables a journal and crash recovery. Different worlds can use different servers. One server owns each world.
