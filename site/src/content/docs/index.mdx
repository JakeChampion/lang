## A real program

Fern reads arguments, streams stdin or files, and returns a `Result`
from anything that can fail — so a Unix-style filter stays short. Here
is the heart of a `grep`. Edit it and press Run.

<FernPlayground
  code={`import "std/string";
import "std/io";

function main(): i32 {
    var argv: string[] = args();
    if (argv.len() < 2) {
        eprint("usage: grep PATTERN");
        return 2;
    }
    var pattern: string = argv[1];

    match (io.read_input("-")) {       // "-" means stdin
        Ok(text) => {
            var found: boolean = false;
            var lines: string[] = text.lines();
            var i: i32 = 0;
            while (i < lines.len()) {
                if (lines[i].contains(pattern)) {
                    print(lines[i]);
                    found = true;
                }
                i = i + 1;
            }
            return if (found) { 0 } else { 1 };  // grep's exit convention
        },
        Err(_) => {
            eprint("grep: read error");
            return 2;
        }
    }
}`}
  autoRun={false}
/>

The [CLI tutorial](tutorial/cli-tool/) grows this into a real tool with

## Every case, handled

`match` has to cover every variant or the build stops. Add a `Triangle`
to `Shape` below and watch the compiler point straight at `area`:

<FernPlayground
  code={`import "std/i32";

enum Shape {
    Circle(i32),          // radius
    Rectangle(i32, i32),  // width, height
}

function area(s: Shape): i32 {
    match (s) {
        Circle(r)       => { return 3 * r * r; },
        Rectangle(w, h) => { return w * h; },
    }
}

function main(): i32 {
    print(area(Circle(5)).to_string());        // 75
    print(area(Rectangle(3, 4)).to_string());  // 12
    return 0;
}`}
/>

Failure travels the same way — as an ordinary value, passed up by `?`:

```fern
import "std/string";

function double(s: string): Option[i32] {
    var n: i32 = s.parse_int()?;   // returns None early if the parse fails
    return Some(n * 2);
}
```

The [Reference](reference/syntax/) has the full grammar, the type
system, and the error-handling rules.

## Good to know

- **macOS means Apple Silicon.** There is no Intel Mac build.
- **WebAssembly covers less than native.** C libraries and subprocesses
  are native-only, and you get a clear error at build time rather than a
  surprise at runtime.
- **The standard library is small on purpose.** Strings, collections,
  iterators, JSON, I/O, HTTP, time, math — it grows when a real program
  needs it to.

[Why Fern](why/) has the fuller account: what it gives up, and how it
compares to Go, Rust, Zig and TypeScript.
