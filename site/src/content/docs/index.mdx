**Fern** is a small, statically-typed compiled language that grows
everywhere — lean binaries for CLI tools, tiny wasm modules for
short-lived edge HTTP servers, and the same source compiling to
arm64 (Linux + macOS), x86-64, and WebAssembly. Fast to start, fresh
to write, and low to the ground.

<CardGrid stagger>
  <Card title="Fast-startup binaries" icon="rocket">
    Native arm64 + x86-64 ELF binaries with no runtime / no GC.
    Compile a CLI tool, link statically, start in milliseconds.
  </Card>
  <Card title="WebAssembly ready" icon="puzzle">
    WASI Preview 2 component output. Drop the `.wasm` into wasmtime
    or any other host with no glue code.
  </Card>
  <Card title="Real LSP, real editor support" icon="laptop">
    `fern-lsp` ships hover, goto-definition, completion,
    signature help, inlay hints, rename, format-on-save, and a
    VS Code extension that wraps it.
  </Card>
  <Card title="Type-checked" icon="approve-check-circle">
    Sized integer types, generics with monomorphisation, tagged-
    union enums with exhaustive pattern matching, `Option` and
    `Result` baked in.
  </Card>
</CardGrid>
