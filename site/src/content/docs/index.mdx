**Fern** is a small, statically-typed compiled language. One source
compiles to lean CLI binaries and tiny wasm edge modules across arm64
(Linux + macOS), x86-64, and WebAssembly.

<CardGrid stagger>
  <Card title="Fast-startup binaries" icon="rocket">
    Native arm64 + x86-64 ELF, no runtime, no GC. Link statically,
    start in milliseconds.
  </Card>
  <Card title="WebAssembly ready" icon="puzzle">
    WASI Preview 2 component output. Drop the `.wasm` into wasmtime
    or any host — no glue code.
  </Card>
  <Card title="Real editor support" icon="laptop">
    `fern-lsp` ships hover, goto-definition, completion, signature
    help, inlay hints, rename, format-on-save, and a VS Code extension.
  </Card>
  <Card title="Type-checked" icon="approve-check-circle">
    Sized integers, monomorphised generics, tagged-union enums with
    exhaustive matching, `Option` and `Result` built in.
  </Card>
</CardGrid>
