# OS text boundary audit

Directory listings reject a malformed name with `IoError.InvalidUtf8`.
The complete listing fails. Callers do not receive a partial array, a
replacement name, or a silently omitted entry. This implements D10's
boundary error for paths that cannot be represented as Fern text.

`read_dir`, `read_dir_all`, `read_dir_ino`, and `read_dir_ino_all` retain
their signatures and report the supplied directory path. `Dir.entries`
reports an empty error path, as its other handle errors do. The descriptor
stays open, and a repeated call has the same validation. Dot filtering and
inode metadata retain their existing behavior for valid input.

| OS producer | Contract |
|---|---|
| Directory names | Native getdents and WASI preview 1 validate before a name enters the result. The Go interpreter checks both listing paths. Preview 2 directory names are canonical ABI strings. |
| `read_link` | Native and WASI validate the returned target and report `InvalidUtf8(path)`. The Go interpreter applies the same rule. |
| `getcwd` | Native and Go validate the current path and report `InvalidUtf8("")`. WASI retains its unsupported result. |
| `mounts` | Native and Go validate all decoded source, target, and filesystem type fields before returning the array. A malformed field returns `InvalidUtf8("")`. WASI retains its unsupported result. |
| `hostname`, `uname_field` | Native and Go validate kernel identity fields. Malformed text returns an empty string, as a failed kernel request does. WASI returns empty text. |
| `args`, `env`, `environ` | Preserve the explicit D10 UTF-8 assumption. These signatures have no encoding-error result; this change does not introduce traps or replacement decoding. |
| Bare and Reader line input | Preserve the explicit D10 exception. Checked file, Reader chunk, and std/io text APIs retain their existing validation. |
| Extended attributes | Attribute names are caller-supplied strings. There is no runtime builtin that lists attribute names. Text getters already reject malformed values; byte getters preserve them. |
| `sysctl` | Returns bytes, with no implicit text conversion. |
| Temporary directory paths | Native paths combine an ASCII root and suffix with the caller's prefix. The Go oracle rejects a malformed host temporary root before creating a directory and reports `InvalidUtf8(prefix)`. |
| Recursive removal | Native and Go can traverse raw names internally. They return no child-name text to the program. Native removal discards recursive child errors; Go classifies errors with the supplied root path. |
| Error messages | Native errno text is a static UTF-8 table. Path payloads use caller-supplied paths. |

The self-host interpreter delegates OS operations to the host runtime.
The regression test therefore also builds the interpreter with the changed
runtime. A compiler built by the older pin still has the pin's runtime for
its own direct `-interp` execution.

The host creates malformed names and link targets for 13 UTF-8 error
classes. The generated Fern source contains only valid paths and expected
text. Tests cover valid multibyte names, whole-list failure, repeated
handle reads, error paths, and malformed current-directory names.

## Validation

The measurements below describe the original source commit `0c9b8297970efbda66533543c1d41177b3c30dc9`.
Current integration checks are in `docs/benchmarks/os-text-2026-10-23/current-integration`.

The new host-input cases pass on x86-64 Linux, ARM64 Linux under QEMU,
WebAssembly core and components, the Go interpreter, and the rebuilt Fern
interpreter. Native and core WebAssembly allocation censuses balance.
Reader text, per-module Reader text, and extended-attribute byte regressions
also pass. The focused self-host run took 48.841 seconds.

The macOS test is present but cannot run on this Linux host. It requires
Apple Silicon. No local macOS execution is claimed.

The pinned bootstrap reaches equal stages 2 and 3 at 14,248,496 bytes.
Their SHA-256 is
`c08e0dab9d7ec4afa636f5f026445a75bb675b33a201e97e1dc4afa0d4f249a9`.
All eleven driver sizes pass the unchanged strict 5% gate.

[Evidence](../benchmarks/os-text-2026-10-23/) includes the original directory
reproducer, before and after results, focused logs, exact source hashes,
bootstrap identities, and driver size checks. The original compiler accepts
each malformed listing. The changed compiler rejects all five APIs while
preserving valid names.
