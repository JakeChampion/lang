# MPEG Layer I playback on native x86-64 Linux

Each stream contains 120 frames generated by cycling the three frames in the pinned Layer I fixture generator. Inputs include unprotected and CRC-protected frames. Seven trials alternated execution order across the prior Fern decoder, the revised decoder, and scalar and SIMD minimp3. Every process ran on the same CPU, performed two warmups, and timed 30 complete in-memory stream decodes. Median times below are wall milliseconds per stream. The timed drivers both hash the first PCM sample and count all samples. Each driver writes its complete final PCM after timing.

| Input | Prior Fern | Revised Fern | Scalar minimp3 | SIMD minimp3 | Fern allocations before / after |
| --- | ---: | ---: | ---: | ---: | ---: |
| MPEG-1 mono, 44.1 kHz | 1.298 | 1.268 | 0.728 | 0.434 | 851 / 733 |
| MPEG-1 stereo, 48 kHz | 1.725 | 1.666 | 0.853 | 0.513 | 971 / 733 |
| MPEG-2 joint stereo, 22.05 kHz | 1.682 | 1.663 | 0.798 | 0.487 | 971 / 733 |

Sharing the 1,728-float synthesis array and 128-float transform array across consecutive frames reduced allocations for all three streams. Median peak RSS rose by 8 KiB for each. The revised decoder took 2.9–3.4 times the SIMD reference time. Its PCM was bit-identical to the prior decoder and scalar minimp3. Maximum absolute difference from SIMD was 2.39e-7 or less. These short synthetic streams have three active subbands and do not establish performance on densely allocated material. [All 84 trials](trials.json)

## Reproduction

Use `scripts/gen-mp1-vectors.py`'s `frame(version, rate_index, mode, ext, seq)` with the first four arguments set to `(1, 0, 3, 0)`, `(1, 1, 0, 0)`, or `(2, 0, 1, 0)`, respectively. Concatenate 120 frames with `seq = i % 3`.

Build `bench/audio/mp1.fern` with the same optimized self-host compiler and the two stdlib trees (baseline `9b3a510a4c`). Build `scripts/audio-reference/mp3_freeformat_bench.c` with `cc -O3 -ffp-contract=off -DFERN_MPEG_LAYERS_12` and headers from pinned minimp3 revision `ea99364f61c14656440e8d77e9c233ccf3124633`. Add `-DFERN_MP3_BENCH_SIMD` for the SIMD build. Run each executable with arguments `INPUT whole 30 OUTPUT.f32 decode`.

## Densely allocated subbands and an independent stream

A second campaign included three 120-frame streams with all 32 subbands allocated, plus the FFmpeg archive's copy of the ISO Layer I test vector `fl1.mpg` (SHA-256 `8bffe46c1a1ba709b35f4782c1a661d0081e8ef84222edcf518ee5e4c2e77f13`). Generate the synthetic inputs as above with `dense=True`. Use `125bed347d` as the prior stdlib. [Archive sample](https://samples.ffmpeg.org/A-codecs/mp1-sample.mp1) · [Sample provenance](https://samples.ffmpeg.org/A-codecs/mp1-sample.txt)

The revised decoder checks the required bits for all twelve sample slots before decoding them. It reads each sample from the one to three bytes occupied by its field. On all four inputs its complete PCM matched both the previous decoder and scalar minimp3 bit for bit. The largest absolute difference from SIMD minimp3 was 4.77e-7. On the archive stream, all 37,632 interleaved samples matched scalar minimp3.

| Input | Prior Fern ms | Revised Fern ms | Scalar ms | SIMD ms | Fern allocations before / after |
| --- | ---: | ---: | ---: | ---: | ---: |
| Dense mono | 2.156 | 2.191 | 0.921 | 0.576 | 733 / 613 |
| Dense stereo | 3.600 | 3.456 | 1.263 | 0.848 | 733 / 613 |
| Dense joint stereo | 3.610 | 3.456 | 1.001 | 0.707 | 733 / 613 |
| ISO Layer I stream | 1.393 | 1.345 | 0.454 | 0.315 | 306 / 257 |

The revised Fern decoder used one fewer allocation per frame and 12 KiB less median peak RSS on each input. Its median wall time was 3.8–4.9 times the SIMD reference. Each of the seven alternating trials used thirty complete decodes per process. [All 112 measurements](dense-trials.json)

## Frame-at-a-time playback

The incremental API retains synthesis history and workspace between frames. The caller can pass a view starting at the next header, advance by the returned byte count and reuse one 768-float output array. The decoder writes only the 384-sample-per-channel prefix. Across ten independent streams, retrying the third frame after a short output buffer and a CRC failure reproduced all PCM bits and left the extra output element intact.

| Input | Whole / incremental Fern ms | Scalar / SIMD frame ms | Whole / incremental Fern peak RSS |
| --- | ---: | ---: | ---: |
| Dense MPEG-1 stereo, 120 frames | 3.291 / 3.242 | 1.050 / 0.680 | 1,000 / 212 KiB |
| ISO Layer I stream, 49 frames | 1.252 / 1.291 | 0.356 / 0.242 | 560 / 184 KiB |

The benchmark preloads the same compressed file in all variants. Each process takes its peak RSS reading before writing the independent-check PCM dump. Frame-mode timing includes hashing the first sample of every frame. Whole-stream timing hashes the first sample of the stream. Each median covers seven trials of thirty decodes. Use the reproduction commands above with mode `frames` in place of `whole` and build the C frame drivers with `-DFERN_MPEG_LAYER_1`. [All 56 measurements](frame-trials.json)
