# A server with no TLS identity links no TLS, 2026-10-29

`net-size-2026-10-21.md` ends with the TLS server side still in a plain
server: `match (opts.tls)` in `__serve_accept` could not fold, because
`semreach` kept variant facts for declared enums only (#12885). Now the
pass keeps them for `Option` and `Result` too. This records the sizes
before and after.

## Method

- Compilers: the self-host compiler at main fe225cb6 (before), and the
  same with the `semreach` change (after), both built from the pinned
  stage0.
- Program: `min_hello`, `serve.run(8080, serve.config(), handle)` with a
  hello handler and no TLS. `TestSelfHostSemReachServeWithoutTLS` holds
  this program.
- Function bytes from `nm -S --size-sort` on a `-g` build, x86-64.

## Sizes in bytes, x86-64

| build | before | after |
|---|--:|--:|
| default | 1,289,024 | 540,928 |
| `-size` | 936,576 | 389,600 |
| functions, `-g` | 1,037,582 | 447,979 |

## Functions by module, `-g`

| module | before | after |
|---|--:|--:|
| std/serve | 274,818 | 235,047 |
| the TLS handshake | 151,662 | 0 |
| x509 | 61,928 | 0 |
| crypto | 49,848 | 0 |
| std/http | 41,066 | 40,886 |
| the TLS message layer | 29,711 | 0 |
| p256 | 24,763 | 0 |
| the TLS server | 19,206 | 0 |
| ed25519 | 18,683 | 0 |

The rest of the TLS stack (the record layer, ecdsa, der,
chacha20poly1305, bigint, mlkem768, rsa and the key share) also goes to
0. The self-host compiler, which uses neither TLS nor HTTP, is 62,208
bytes smaller (22,260,912 to 22,198,704).

## What changed

- `semreach` gives the variants of an `Option` and a `Result` keys, as
  it does for a declared enum. A `variant_new` builds one.

- An `Option` or a `Result` that a built-in makes has no `variant_new`.
  So any other operation that gives one arrives: all its variants are
  built.

- A read, a copy, a phi, a select, a parameter and a closure call pass a
  value on and do not arrive. A zero value is `None`, so it arrives.

- A variant test is true when nothing builds its siblings. So the `Err`
  arm of a `Result` that only an `Ok` builds is not reached.

## How to rerun

```
bin/fern-selfhost -size -target x86-64-linux -o S PROGRAM internal/stdlib
bin/fern-selfhost -g -target x86-64-linux -o S.g PROGRAM internal/stdlib && nm -S --size-sort S.g
```
