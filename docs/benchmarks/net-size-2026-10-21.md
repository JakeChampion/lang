# What a server links that it cannot use, 2026-10-21

The binary-size row of #9851 §7 (`net-targets-2026-10-14.md`) was last
measured on 2026-10-14, before HTTP/3 landed in std/serve (#9861's
successor, `docs/NET-P8-HTTP3-PLAN.md`). Measured again on main at
2210347, every server had grown by about half a megabyte: a plain
HTTP/1.1 hello carried the whole HTTP/3 stack, QUIC, QPACK, the TLS
client and server handshakes and X.509, none of which its configuration
could enable. This records what kept each reachable, what changed, and
the sizes before and after.

## Method

- Compiler: `bin/fern-selfhost` from the pinned stage0 on the branch,
  against the stdlib at main (before) and the branch's (after); the
  compiler change (an enum's zero is no value) is part of "after".
- Programs: `min_hello`, `serve.run` with `serve.config()` and a hello
  handler, no TLS; `tls_hello`, the semreach test's
  `serveWithoutH3Prog`, TLS by `TLS_PEM` and no HTTP/2 or HTTP/3, the
  shape the §7 row names; `hello`, `scripts/net-bench.d/hello.fern`,
  which takes TLS, HTTP/2 and HTTP/3 from its environment, so it
  legitimately links all three.
- The reachability pass's own decisions (which type arrives opaque and
  where, which variant is built, which field widens) read from a local
  instrumented build, and `nm -S --size-sort` on a `-g` build for the
  split by module.

## What kept HTTP/3 reachable, and the fix for each

Each was found by following the pass and confirmed by the symbol list.

1. **`fd == conns.quic.sock`.** The loop asked whether a ready
   descriptor was the QUIC socket. With no socket the field is -1, which
   the pass knows, but the descriptor is any value, so the comparison
   could not be decided and the datagram path behind it was reached:
   `__h3_event`, `__h3_accept`, `h3q.server`, `quic.accept`, and
   through the connection the TLS client (QUIC's handshake runs both
   roles). Now `__quic_owns` asks first whether there is a socket.
2. **The per-pass tick.** `__h3_pass` and `__h3_start_all` ran every
   pass; the pass returned at once without a socket, but the start's
   guard counted `burst.touched`, an `i32[]` the pass cannot know is
   empty, so `__h3_flush` and QUIC's whole output side (`conn.__plan`,
   `probe_out`, `seal`, the stream table) stayed. Both now run under
   `__quic_on`, and the pass's own early return is gone.
3. **A flight's QUIC serial.** `__Flight.quic` was -1 for a TCP
   request, and the three `fl.quic >= 0` tests chose the HTTP/3 answer
   path. The async lowering lifts a flight local to its frame and starts
   it at a zero record, whose `quic` is 0; joined with -1 that is any
   value, so `__h3_respond`, `h3q.Conn.respond_head` and `h3.Session`'s
   senders were reached. The field now uses 0 for none, as `stream`
   already did, and serials start at 1.
4. **An enum's zero.** The same lifting starts `let tls: __Tls = Plain`
   in `__serve_accept` at a zero, and the pass took a zero of any
   non-record type as an arriving value, making `__Tls` opaque: every
   variant built, so the TLS session paths (`Secured`, `Awaiting`,
   `InKernel`) were all live. A zero of an enum is the null word, which
   is no variant; the pass now treats it like a record's zero rather
   than an opaque value (`semreach.semantic_arrives`).
5. **`__quic_none()` built a QUIC config.** `quic.config([])` set its
   roots with `verify.roots([])`, which parses each certificate it is
   given, so `x509.parse`, `der` and `verify` were reached from a worker
   with no QUIC. `verify.no_roots()` builds the empty store directly
   and is what every "no roots" site now calls.

## What a plain server still links

`min_hello` after, `-size`, x86-64: 663,658 bytes of functions. By
module: std/serve 145,507; the TLS handshake 66,314; crypto 48,416;
x509 37,018; std/http 24,324; ecdsa 18,122; p256 15,978; the TLS
server 10,551; der 9,722; ed25519 9,638; the record layer 9,567. The
TLS server side, about 270 KB in all, is linked by a server whose
`Config.tls` is `None` because `Option` has its own layout
(`semrecords.layout_option`) and the pass keeps no variant facts for
it: `match (opts.tls)` cannot fold. That is the next item for the
§7 row and is filed separately (#12885).

## How to rerun

```
bin/fern-selfhost -size -target x86-64-linux -o S PROGRAM internal/stdlib
bin/fern-selfhost -size -g -target x86-64-linux -o S.g PROGRAM internal/stdlib && nm -S --size-sort S.g
```
