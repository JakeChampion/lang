# x86_64ssa: unwind data

**Date:** 2026-09-16

## Why

Building the default-backend flip and running the gates against it turned up
the blocker: `TestNativeLinkPlacesEhFrame` failed. Neither SSA backend emitted
a single `.cfi_*` directive, where both stack-machine emitters do, each with
its own `cfi_emit_test.go`. Every binary built today carries `.eh_frame`; with
SSA as the default they would carry none, and a profiler, debugger or
backtrace could not walk out of a frame.

Worth recording how it got that far: the corpus differential compares what
programs *do*, and 328 of 328 agreeing says nothing about what the artefact
*carries*. Behaviour parity is not artefact parity. Two sibling gaps had the
same shape and are fixed in #9493.

## Change

The prologue carries the same rules the stack-machine emitter emits:
`.cfi_startproc`, the CFA moving to rsp+16 as rbp is pushed, rbp's own
location, then the CFA tracked through rbp. Once rbp is the CFA register the
rule holds for the whole body, so neither the spill reservation nor the
callee-saved pushes need to touch it.

Each return brackets its teardown with `.cfi_remember_state` and
`.cfi_restore_state`, which a single-epilogue emitter gets for free. This one
returns from every block that ends in a return, and blocks are emitted in
layout order, so a rule left in effect after an epilogue would describe
whatever block came next.

## What it costs, and why it is shaped this way

The driver binary goes from 8,817,371 to 9,388,731 bytes, 6.5%, all of it
`.eh_frame`. The shape of the emitter is the reason:

| | this backend | stack-machine emitter |
|---|---|---|
| functions | 5,087 | 5,089 |
| return sites | 17,766 | one epilogue each |

A first cut also described where each callee-saved register went, which is
information the other emitter never provided, and at 3.5 returns per function
it cost a further 772 KB. Those rules are gone: this emits what the other one
emits and no more.

The structural fix is the other emitter's shape — route every return through
one epilogue per function. That would pay back most of the `.eh_frame` and
some `.text` too, since 17,766 teardowns become 5,087. It is a codegen change,
so it is its own slice rather than a rider on this one.

## Tests

- `TestEveryFunctionCarriesBalancedCFI`: a function with two returns, so the
  layout puts a block after an epilogue. Start and end proc balance, remember
  and restore balance, and every `ret` re-describes the CFA before it.
- `TestPrologueCFIDescribesTheFrame`: the prologue's rules appear in the order
  the frame is actually built.
- `TestNativeLinkPlacesEhFrame` is the end-to-end gate this unblocks, and the
  hand check is a `-backend ssa` build of fib: it exits 34 and its image
  carries a CIE.
- `rspDeltaAtCalls` in the alignment tests now skips `.cfi_` lines. They
  assemble to no bytes, so they move nothing, and reading one as the
  instruction that ends the prologue made three alignment tests report
  failures that were not there.
