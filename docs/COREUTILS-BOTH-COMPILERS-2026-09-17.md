# The coreutils under both Fern compilers — 2026-09-17

Status: [measurement] — the first run of `scripts/coreutils-bench`'s
two-compiler leg (#9521). `fern` is `bin/fern`'s build of a utility and
`fern-sh` is `bin/fern-selfhost`'s build of the same source, both with `-O`.
The standing definition is `docs/COREUTILS.md`; the summary and what it means
for the epic's second requirement live in that file's Performance section.
This file is the raw run.

Host: 4-core x86-64 Linux container, GNU coreutils 9.4, uutils 0.11.0,
`fern b73bff9`. Wall time under hyperfine, mean ± σ; a cell names its run
count where the row was capped below 20. **Only comparable within one run on
one machine** — never paste a column from here beside another machine's.

Run in two batches, each with nothing else on the machine: batch A is the
startup-bound and line-oriented utilities, batch B the compute-bound ones.
A ratio is mean(first) / mean(second), so above 1 the second-named build is
faster; in a `gnu / …` or `uutils / …` column, above 1 means Fern is faster.
