lang playground

Edit a lang program on the left, hit Run (or Ctrl/Cmd+Enter), and see its output on the right. Drives the in-tree AST interpreter (no codegen, no link) compiled to wasm. The editor is CodeMirror 6; hover for types, Ctrl/Cmd+Space for completion, inline squiggles for errors — all powered by the in-process language server the same cmd/lang-lsp binary speaks. State is fresh per run. Share encodes the source into the URL so you can hand someone a snippet without a server.
