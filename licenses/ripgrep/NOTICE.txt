examples/rg/testdata/ripgrep-tests.json holds the cases of the integration tests of ripgrep 14.1.1.
Reference: https://github.com/BurntSushi/ripgrep/tree/14.1.1/tests
Each case has the files that the test makes, its command line, its directory and its standard input.
The cases do not hold the expected output. The test runs ripgrep itself for that.

examples/rg/testdata/sherlock-nul.txt is tests/data/sherlock-nul.txt of ripgrep 14.1.1.
examples/rg/types.fern holds the file types that ripgrep 14.1.0 writes with --type-list.
