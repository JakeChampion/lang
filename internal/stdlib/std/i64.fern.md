# 64-bit integer methods

This module provides signed 64-bit integer methods.

## Model

The module extends signed 64-bit values with arithmetic, number properties, bit operations, and text conversion.

## Contracts

Checked operations return an optional result. Saturation operations bound the result. Ordinary operations retain the language arithmetic rules.

## Executable example
