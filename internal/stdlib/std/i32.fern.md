# 32-bit integers and byte properties

This module provides signed 32-bit integer methods.

## Model

Integer methods cover arithmetic, bit operations, and text conversion. Byte methods test ASCII properties without a Unicode interpretation.

## Contracts

Checked, saturation, and ordinary arithmetic have different overflow contracts. Choose the method whose contract matches the input range.

## Executable example

  let n: i32 = -12;

  if (d == 0) {
    return 0;

  let q: i32 = n / d;
  let r: i32 = n % d;
