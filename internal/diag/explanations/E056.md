# E056 — cannot assign to an array element

Array elements are immutable after construction. A subscript assignment
`arr[i] = v` is the element-level counterpart of the field-assignment ban
(E048); together they make Fern's data structures immutable, which is what
lets reference cycles stay unconstructible (so Perceus reference counting
needs no cycle collector — see `docs/LANGUAGE-DIRECTION.md`).

## What is rejected

```
var xs: i32[] = [1, 2, 3];
xs[0] = 9;               // error[E056]
```

## Fixing it

Build a new array with the element replaced, using `with`, and rebind:

```
xs = xs.with(0, 9);      // xs is now [9, 2, 3]
```

`with` returns a fresh array; the old one is reclaimed when its last
reference drops.
