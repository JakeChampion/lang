# E046 — Tuple field access error

Two related errors when accessing a tuple element:

- **Non-numeric field name.** Tuples are positionally
  indexed; the `.field` syntax requires a numeric literal
  (`.0`, `.1`, `.2`, …).
- **Index out of range.** A `(i32, string)` tuple has
  elements `.0` and `.1`; `.2` rejects.

## Example

```
function main(): i32 {
    var t: (i32, string) = (1, "hi");
    return t.first;             // error[E046]: tuple field access requires a numeric index, got "first"
}

function main2(): i32 {
    var t: (i32, string) = (1, "hi");
    return t.2;                 // error[E046]: tuple has 2 elements; index 2 is out of range
}
```

## Fix

Use the numeric index. If you want named access, use a
struct instead of a tuple:

```
function main(): i32 {
    var t: (i32, string) = (1, "hi");
    return t.0;                 // 1
}

struct Named { first: i32, label: string }
function main2(): i32 {
    var n: Named = Named { first: 1, label: "hi" };
    return n.first;             // 1
}
```

## When to use tuples vs structs

- **Tuples**: small, ad-hoc, the field meaning is clear
  from position (returning a pair from a function;
  destructuring a slice into low / high bounds).
- **Structs**: anything with three or more elements, or
  where field meaning isn't positionally obvious.
