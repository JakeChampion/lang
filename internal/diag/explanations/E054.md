# E054 — an `@export` function cannot be generic

A function marked `@export` (a component-model world export) is part of the
module's external ABI: the host calls it across the component boundary with
one fixed, concrete signature. A generic function has no single concrete
signature — it is a family of functions, one per instantiation — so there is
nothing stable to expose at the boundary.

## What is rejected

```
@export
function map[T](x: T): T { return x; }   // error[E054]
```

## Fixing it

Export a concrete instantiation instead of the generic itself — write a
non-generic wrapper with the exact ABI the world expects and have it call the
generic internally:

```
function map[T](x: T): T { return x; }

@export
function map_i32(x: i32): i32 { return map(x); }
```
