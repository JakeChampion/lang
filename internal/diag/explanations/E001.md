# E001 — Undefined identifier

The compiler couldn't find a declaration for the name you used.

## Example

```
function main(): i32 {
    return total + 1;  // error[E001]: undefined identifier "total"
}
```

## Fix

Either declare the variable before use, or check that the
name is spelled the same as the declaration. The checker
suggests close matches; "did you mean `count`?" usually
points at the right answer.

```
function main(): i32 {
    var total: i32 = 41;
    return total + 1;
}
```
