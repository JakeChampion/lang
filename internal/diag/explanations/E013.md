# E013 — Variable already declared in this scope

Two `var` declarations in the same scope share a name. Fern
doesn't allow shadowing within a single block; each name
must be unique among its peers.

Function-level shadowing across nested scopes IS allowed —
an inner block can introduce a new `x` that's distinct from
the outer `x`. The error fires only when the conflict
happens within the same `{ … }` region.

## Example

```
function main(): i32 {
    var x: i32 = 1;
    var x: i32 = 2;   // error[E013]: variable "x" already declared in this scope
    return x;
}
```

## Fix

Pick a different name for the second declaration, or use
assignment if you're updating the existing variable.

```
function main(): i32 {
    var x: i32 = 1;
    x = 2;
    return x;
}
```

For nested-scope shadowing (legal):

```
function main(): i32 {
    var x: i32 = 1;
    if (true) {
        var x: i32 = 99;   // OK — different scope
        return x;
    }
    return x;
}
```
