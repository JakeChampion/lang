# E077 — invalid named argument

Named arguments (`f(b = 2, a = 1)`) are resolved against the callee's
declared parameters before type-checking. This error covers the ways that
resolution can fail.

## What is rejected

**A named argument on anything but a direct call to a named function.**
Methods and calls through a function value have no declaration to match
names against at this stage:

```
var f: (i32) => i32 = …;
f(x = 1);              // E077
obj.method(x = 1);     // E077
```

**A name no parameter carries:**

```
function listen(port: i32, backlog: i32 = 128): i32 { … }
listen(port = 80, backlogg = 5);      // E077: no parameter named "backlogg"
```

**The same parameter supplied twice**, positionally and by name or twice by
name:

```
listen(80, port = 81);                // E077: duplicate argument for "port"
```

**A positional argument after a named one.** Once names start, every
remaining argument must be named, so the mapping stays unambiguous:

```
listen(port = 80, 5);                 // E077
```

## Note

A genuinely missing or surplus argument is an arity error (E004), not this
one, and an unusable default value is E076.
