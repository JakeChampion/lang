# E015 — Variant payload count mismatch

A `match` arm (or `if let` / `let else`) bound a different
number of payloads than the variant declares. The checker
expects exactly one binding name per payload type.

## Example

```
enum Shape {
    Circle(f64),
    Rect(f64, f64),
}

function area(s: Shape): f64 {
    match (s) {
        Circle(r) => { return r * r; },
        Rect(w) => { return w; },   // error[E015]: variant Rect has 2 payload(s), got 1 binding(s)
    }
}
```

## Fix

Bind all payloads. Use `_` to ignore unused ones explicitly.

```
function area(s: Shape): f64 {
    match (s) {
        Circle(r) => { return r * r; },
        Rect(w, h) => { return w * h; },
    }
}
```

For variants with no payloads, omit the parentheses entirely:

```
enum Maybe { Yes, No(string) }

match (m) {
    Yes => { print("yes"); },        // no `()` for empty payload
    No(reason) => { print(reason); }, // one binding for one payload
}
```
