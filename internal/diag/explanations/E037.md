# E037 — Slice error

A slice expression `arr[lo:hi]` had one of three problems:

- **Low bound isn't i32.** The `lo` index must be `i32`.
- **High bound isn't i32.** Same for `hi`.
- **Source isn't sliceable.** The scrutinee isn't an array,
  slice, or string.

## Examples

```
function main(): i32 {
    var xs: i32[] = [1, 2, 3, 4];
    var i: i64 = 0 as i64;
    var s = xs[i:2];           // error[E037]: slice low bound must be i32, got i64

    var n: i32 = 42;
    var bad = n[0:1];          // error[E037]: cannot slice value of type i32
    return 0;
}
```

## Fix

Cast the bounds to `i32`, or correct the slice source.

```
function main(): i32 {
    var xs: i32[] = [1, 2, 3, 4];
    var i: i64 = 0 as i64;
    var s = xs[(i as i32):2];
    return s[0];
}
```

## Why i32

Array indices in Fern are i32 — same shape as `len(arr)`
returns. Wider integer types would silently truncate or
overflow on cast. The error forces the cast to be visible.
