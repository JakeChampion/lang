# E011 — `break` or `continue` outside a loop

A `break` or `continue` statement appeared outside any loop or
switch context. Lang's control flow doesn't allow jumping out
of regions that aren't bounded by an iteration construct.

`break` is also valid inside a `switch` (to exit a case
early); `continue` is loop-only.

## Example

```
function main(): i32 {
    if (true) {
        break;   // error[E011]: break outside of a loop or switch
    }
    return 0;
}
```

## Fix

Wrap the `break` / `continue` in a loop, or replace it with
the equivalent early-return / state-flag pattern when the
intent was "exit this conditional region."

```
function find_first_negative(xs: i32[]): Option[i32] {
    var i: i32 = 0;
    while (i < len(xs)) {
        if (xs[i] < 0) {
            return Some(xs[i]);
        }
        i = i + 1;
    }
    return None;
}
```
