# E034 — Array / indexing error

Three array-related errors share this code:

- **Array element type mismatch**: an array literal's
  element has a type that doesn't match the inferred
  element type.
- **Index must be an integer**: `arr[expr]` where `expr`
  isn't an integer.
- **Indexing non-array value**: `expr[...]` where `expr`
  isn't an array, slice, or string.

## Examples

```
function main(): i32 {
    var xs: i32[] = [1, "two"];   // error[E034]: array element type string, expected i32

    var i: f32 = 0.5;
    var x: i32 = xs[i];           // error[E034]: index must be an integer, got f32

    var n: i32 = 42;
    return n[0];                  // error[E034]: indexing non-array value of type i32
}
```

## Fix

- **Element mismatch**: cast / convert the element to fit,
  or pick a wider literal type.
- **Non-integer index**: cast the index expression to an
  integer.
- **Non-array indexing**: confirm you meant to index — the
  scrutinee is just an integer.

```
function main(): i32 {
    var xs: i32[] = [1, 2];
    var i: i32 = 0;
    return xs[i];
}
```
