# E016 — Union declaration error

The union declaration is malformed in one of four ways:

- **Name collides with a struct of the same name.** Fern's
  type namespace is shared between structs, enums, and unions
  — each must be unique.
- **Name collides with an enum of the same name.** Same
  rule.
- **Duplicate member.** A union member appeared twice in the
  decl (`type Either = A | B | A;`). Pick one.
- **Member doesn't name a struct in scope.** Unions list
  struct types — non-struct members aren't supported.
- **Member is generic.** `type X = Box[i32] | Box[string];`
  with a generic struct member isn't supported yet — that's
  ambiguous resolution territory (which instantiation of
  Box?). Use concrete struct types for now.

## Example

```
struct Either { value: i32 }
type Either = Foo | Bar;   // error[E016]: union "Either" collides with a struct of the same name
```

## Fix

Rename one of the colliding declarations.

```
struct EitherValue { value: i32 }
type Either = Foo | Bar;
```
