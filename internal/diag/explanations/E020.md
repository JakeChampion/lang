# E020 — Empty array literal needs a type annotation

An array literal `[]` with no elements can't have its element
type inferred — there's nothing inside to infer FROM. Fern
asks for an explicit annotation on the declaration that owns
the literal.

## Example

```
function main(): i32 {
    var xs = [];   // error[E020]: empty array literal needs a type annotation
    return 0;
}
```

## Fix

Add the type annotation on the variable:

```
function main(): i32 {
    var xs: i32[] = [];
    return 0;
}
```

Non-empty literals don't need the annotation — the element
types fix the array type unambiguously:

```
function main(): i32 {
    var xs = [1, 2, 3];   // inferred as i32[]
    return xs[0];
}
```

- E002 (type mismatch) — fires when the annotation IS
  supplied but the element types disagree.
