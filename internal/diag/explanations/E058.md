# E058 — labelled `break` / `continue` names no enclosing loop

A labelled `break label;` or `continue label;` must name a loop that
lexically encloses it. The label here matches none — it is misspelled, or the
loop it referred to does not actually contain this statement.

## What is rejected

```
outer: while (a) {
    while (b) {
        break inner;     // error[E058]: no enclosing loop is labelled `inner`
    }
}
```

## Fixing it

Use the label of an actual enclosing loop:

```
outer: while (a) {
    while (b) {
        break outer;     // jumps out of the `outer` loop
    }
}
```

Check the spelling, and that the labelled loop really does contain the
`break` / `continue`.
