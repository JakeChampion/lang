# E063 — returning a `[T]` slice that views function-local storage

A `[T]` slice is a **non-owning** `{data_ptr, len}` view. It carries no
reference-count handle on the array it points into, so it stays valid
only as long as that backing array does. Returning a slice whose backing
storage was allocated *inside the function* is therefore a use-after-free:
the moment the function returns, the frame's last owning reference to the
array drops, the storage is reclaimed, and the returned `data_ptr` dangles.

This is the lifetime contract from `docs/LANGUAGE-DIRECTION.md` ("Slice /
view lifetime contract") made into a checked rule — the language otherwise
goes to great lengths (E048/E049/E057, the RC never-over-release invariant)
to make memory errors unconstructible.

## What is rejected

Returning a slice the checker can prove views function-local storage:

- a slice of an **array literal** — `return [1, 2, 3][0:2];`
- a slice of a **locally-declared owned array** (`var xs = […]; return xs[0:2];`)
- a local **slice binding** that (transitively) views either of the above
  (`var s = xs[0:2]; return s;`), and sub-slices thereof

## What is allowed

- **String slices** — `s[1:4]` copies into a fresh owned `string`
  (`__str_slice`), so there is nothing to dangle.
- **Slices of a parameter or receiver** — the caller owns the backing
  array, which outlives the call: `function head(xs: i32[]): [i32] { return xs[0:2]; }`.
- **Returning the owned array itself** (`T[]`) — that's a move, not a view.

## Example

```
// error[E063]: the backing array is reclaimed when "first_two" returns
function first_two(): [i32] {
    var xs: i32[] = [1, 2, 3];
    return xs[0:2];            // slice views local `xs` — dangles
}

// OK: `xs` is owned by the caller, so the view stays valid.
function first_two(xs: i32[]): [i32] {
    return xs[0:2];
}

// OK: return the owned array (a move), then slice at the call site
// where the owner is live.
function build(): i32[] {
    return [1, 2, 3];
}
```

## Fixing it

Either return an owned array (`T[]`) and let the caller slice it while the
owner is live, or take the buffer as a parameter so the caller's array
(which outlives the call) is the one being viewed.
