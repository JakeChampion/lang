# P002 — Numeric literal error

A numeric literal had a problem the parser detected:

- **Unexpected suffix on integer.** Suffixes (`i32`, `u64`,
  etc.) must match the literal's shape. Putting a float
  suffix (`f32`) on an integer literal (`42f32` without a
  decimal point) is rejected.
- **Invalid float literal.** The lexer accepted the float-
  shaped token, but converting it to a numeric value
  failed (e.g. `1.e` is malformed).
- **Unexpected suffix on float.** A float literal with
  an integer-only suffix.

## Examples

```
function main(): i32 {
    let x = 42i32;       // OK — explicit i32 typing
    let y = 42f32;       // error[P002]: unexpected numeric suffix "f32" on integer literal
                          // (use 42.0f32 if you meant float)
    let z = 1.5i32;      // error[P002]: unexpected numeric suffix "i32" on float literal
    let w = 1.e;         // error[P002]: invalid float literal "1.e": ...
    return x;
}
```

## Fix

Match the suffix to the literal's shape:

```
function main(): i32 {
    let x: i32 = 42;          // type inferred from annotation
    let y: f32 = 42.0;        // float literal needs a decimal point
    let z: f32 = 1.5;
    let w: f64 = 1.0;
    return x;
}
```

## Supported suffixes

- Integer: `i32`, `i64`, `u8`, `u32`, `u64`
- Float: `f32`, `f64`
