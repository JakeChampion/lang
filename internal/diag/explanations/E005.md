# E005 — Struct literal missing field

A `Struct { f1: …, f2: … }` literal didn't initialise every
declared field of the struct. Fern doesn't support field
defaults — every field must be assigned.

## Example

```
struct Point { x: i32, y: i32 }

function main(): i32 {
    var p: Point = Point { x: 1 };   // error[E005]: struct literal missing field "y"
    return p.x;
}
```

## Fix

Supply every field, in any order:

```
function main(): i32 {
    var p: Point = Point { x: 1, y: 0 };
    return p.x;
}
```

## Why no defaults

Defaults bake assumptions into the type: every callsite would
otherwise need to know what `y` defaults to when omitted, and
changing the default later becomes a quiet semantic change.
Explicit construction makes the assumption visible. Future
helpers (`Point.zero()` etc.) can encapsulate the common
shape if it becomes a problem.
