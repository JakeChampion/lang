# E061 — block-expression has no trailing value

A block used in value position (`var x = { … };`, an `if` / `match` arm whose
result is used, a function body whose value is returned implicitly) must end
in an **expression** that produces its value. Here the block's last element is
a `;`-terminated statement, so the block yields nothing — but a value is
required at this position.

## What is rejected

```
var x: i32 = {
    var a: i32 = 1;
    a + 1;               // error[E061]: trailing `;` makes this a statement, so the block has no value
};
```

## Fixing it

Drop the trailing `;` on the final expression so it becomes the block's value:

```
var x: i32 = {
    var a: i32 = 1;
    a + 1                // no `;` — this is the block's value (2)
};
```
