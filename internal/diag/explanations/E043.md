# E043 — Struct literal field error

Three related errors when constructing a struct literal:

- **Unknown struct type.** `Foo { x: 1 }` where `Foo` isn't
  declared (close to E001 but specific to struct-literal
  contexts).
- **No such field.** The literal mentions a field name that
  isn't on the declared struct.
- **Field type mismatch.** A field's value has a type that
  doesn't match the declared field type.

## Examples

```
struct Point { x: i32, y: i32 }

function main(): i32 {
    var p = Point { x: 1, y: 2, z: 3 };   // error[E043]: struct Point has no field "z"

    var q = Point { x: 1, y: "two" };     // error[E043]: field "y": expected i32, got string

    var r = Unknown { x: 1 };             // error[E043]: unknown struct type "Unknown"
    return p.x;
}
```

## Fix

- **Unknown struct**: spell the type name correctly or
  declare it.
- **No such field**: drop the bogus field, or add it to
  the struct declaration.
- **Field type mismatch**: convert the value to the right
  type.

```
function main(): i32 {
    var p = Point { x: 1, y: 2 };
    return p.x;
}
```

## See also

- E005 (struct literal missing field) — the dual error:
  fewer fields than the struct declares (E005) vs more /
  wrong-named fields (E043).
- E002 (type mismatch) — broader category for the field
  type case.
- E001 (undefined identifier) — when the typo is on a
  value name, not a field or type.
