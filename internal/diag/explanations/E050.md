# E050 — Use of an owned parameter after it was consumed

An `own` (owned / consuming) parameter may be **consumed at most
once** on any execution path. After it's consumed, the value is
moved away and can no longer be used — using it again is this
error.

A parameter is *consumed* by a **whole-value** use: matching it
(`match (x)`), returning it, passing it as an argument **to another
`own` parameter**, binding it to a variable, or storing it into a
struct / tuple / array / enum. It is only *borrowed* — and so may be
read repeatedly — by a **projection**: a field read (`x.field`), an
index (`x[i]`), or a method call on it (`x.method()`), and by passing
it to a **borrowed** parameter, which is the default.

That last distinction is the one to keep straight: `f(x)` moves `x`
only when `f` declares its parameter `own`. Handing the same value to
a borrowing callee twice is fine — the callee never took ownership.

This affine discipline is what lets the callee take ownership of an
`own` argument and reclaim or reuse its memory in place (Fern's
Perceus-style FBIP). A borrowed parameter (the default, no `own`)
has no such restriction — the caller keeps ownership.

## Example

```
function take(own xs: i32[]): i32 { return xs[0]; }

function f(own xs: i32[]): i32 {
    var a: i32 = take(xs);   // consumes xs — the callee takes ownership
    return take(xs) + a;     // error[E050]: xs was already consumed
}
```

This example read `sum(xs: i32[])` — a *borrowed* parameter — until
`conformance/cases/diag_e050` required an example that produces the
error. It did not: both calls only borrowed, so the program compiled.

## Fix

Read everything you need from the value *before* consuming it, and
consume it exactly once:

```
function f(own xs: i32[]): i32 {
    var first: i32 = xs[0];   // borrow — fine to repeat
    var second: i32 = xs[1];  // borrow
    return first + second;    // never consumes xs at all
}
```

Or, if two consuming uses are genuinely needed, drop the `own` so
the parameter is borrowed (the caller keeps it):

```
function f(xs: i32[]): i32 {   // borrowed — no consume restriction
    return sum(xs) + sum(xs);
}
```
