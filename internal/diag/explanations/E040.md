# E040 — Generic type-parameter inference / arity error

Two failure modes when calling a generic function or
constructing a generic struct:

- **Wrong type-arg count at the call site.** When the user
  supplies explicit type arguments, they must match the
  generic decl's parameter count.
- **Inference failed.** The call's argument types didn't pin
  down every type parameter; the checker asks for an
  explicit annotation. (Lang doesn't yet accept explicit
  `foo[i32, string](...)` syntax — annotations have to live
  on the binding variable.)

## Examples

```
function pair[A, B](a: A, b: B): (A, B) { return (a, b); }

function main(): i32 {
    var p = pair(1, "hello");     // OK — inferred as (i32, string)
    return p.0;
}

function take[T](): T { ... }     // (hypothetical zero-arg generic)

function main2(): i32 {
    var x = take();               // error[E040]: could not infer type parameter T for take — explicit type args are not supported yet
    return 0;
}
```

## Fix

Add an annotation on the binding so the checker can
back-propagate:

```
function main2(): i32 {
    var x: i32 = take();
    return x;
}
```
