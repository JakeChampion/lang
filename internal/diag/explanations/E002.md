# E002 — Type mismatch

The expression has a type that doesn't fit the position it
appears in.

Common forms:
- A `return` whose value's type doesn't match the function's
  declared return type.
- A `var x: T = …` initialiser whose type isn't `T`.
- A function call whose argument types don't match the
  signature.

## Example

```
function f(): i32 {
    return true;   // error[E002]: return type mismatch
}
```

## Fix

Either change the expression to produce the expected type, or
fix the declaration to accept what the expression produces.
For numeric types, an explicit `as i64` / `as f32` cast is
the right tool — the checker doesn't widen implicitly across
integer types.

```
function f(): boolean {
    return true;
}
```

## See also

- E003 (assignment type mismatch) — the same shape on the
  left-hand-side of `=`.
