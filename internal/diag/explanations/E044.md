# E044 — Captured variable has unsupported type

A closure / lambda tried to capture a variable whose type
Fern's closure-conversion machinery doesn't yet support.
Today's allowed capture types are limited to the
pointer-shaped values that round-trip cleanly through the
closure environment block (string, struct, array, slice,
enum) plus i32 / i64 / f32 / f64.

## Example

```
function main(): i32 {
    var tup: (i32, string) = (1, "hi");
    var f = fn() => tup.0;   // error[E044]: captured variable "tup" has unsupported type (i32, string)
    return f();
}
```

(Tuples-by-value through closure captures are unsupported
in the current closure-conversion pass; the workaround is
to either project the field out before the closure or wrap
the tuple in a struct.)

## Fix

Either project the captured fields to individually-
supported types:

```
function main(): i32 {
    var tup: (i32, string) = (1, "hi");
    var first: i32 = tup.0;
    var f = fn() => first;
    return f();
}
```

…or move the value through a struct (which IS supported):

```
struct Pair { x: i32, s: string }
function main(): i32 {
    var p: Pair = Pair { x: 1, s: "hi" };
    var f = fn() => p.x;
    return f();
}
```
