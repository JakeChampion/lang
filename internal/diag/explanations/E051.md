# E051 — Argument to an owned parameter must be an owned value

A function declared a parameter `own` (owned / consuming), and a call
passed it a value the caller does **not** own and so cannot transfer.

An `own` parameter takes ownership of its argument: the callee may
consume, reclaim, or reuse it. So the argument has to be a value the
caller can give away — a **fresh construction** (a struct / tuple /
array / map literal, a string concatenation, or a variant-constructor
call), **another `own` parameter** of the calling function, or a **local
at its last use**. A *borrowed* value — a borrowed parameter, or a field or
index read — is owned by someone else, so it can't be handed off.

## Example

```
function consume(own xs: i32[]): i32 { return xs[0]; }

function f(xs: i32[]): i32 {   // xs is BORROWED — f doesn't own it
    return consume(xs);        // error[E051]: can't transfer a borrowed value
}
```

## Fix

Pass a value you own — e.g. a fresh construction:

```
function g(): i32 {
    return consume([1, 2]);    // fresh array → owned, transfers fine
}
```

…or thread ownership through, making the caller `own` it too:

```
function f(own xs: i32[]): i32 {   // now f owns xs
    return consume(xs);            // transfer OK (xs is consumed exactly once)
}
```

If the callee only needs to *read* the value, drop the `own` on its
parameter so it borrows instead — then any value, owned or borrowed,
can be passed.

## Transfers of a value you already hold

A local or a field is owned by *this* frame, so it can be transferred
where nothing can read the old binding afterwards:

```
var t: i64[] = s.with(0, 1i64);
return bump(t);                         // t is never read again
a = grow(a, 1);                         // a is rebound to the result:
                                        // its old value is consumed
a = Asm { ...a, cfi: record(a.cfi, v) };  // the store supersedes the one
                                        // field the call consumes
return Asm { ...a, cfi: record(a.cfi, v) };  // nothing runs after a return
```

Each needs the name to occur exactly once in the value (`a.cfi` once, and
`a` bare only as the spread base), the argument to sit directly in the
`own` position, and — for the field form — a base that is an `own`
parameter or a local, never a borrowed parameter.

A local's last use is decided the way the compiler decides where it can
move the value: a read after the call, a transfer inside a loop (the call
runs again), or a read from a `defer` or a closure keeps the value alive,
so each of those stays E051.
