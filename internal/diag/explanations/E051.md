# E051 — Argument to an owned parameter must be an owned value

A function declared a parameter `own` (owned / consuming), and a call
passed it a value the caller does **not** own and so cannot transfer.

An `own` parameter takes ownership of its argument: the callee may
consume, reclaim, or reuse it. So the argument has to be a value the
caller can give away — a **fresh construction** (a struct / tuple /
array / map literal, a string concatenation, or a variant-constructor
call) or **another `own` parameter** of the calling function. A
*borrowed* value — a borrowed parameter, a field or index read, or a
plain local — is owned by someone else, so it can't be handed off.

## Example

```
function consume(own xs: i32[]): i32 { return xs[0]; }

function f(xs: i32[]): i32 {   // xs is BORROWED — f doesn't own it
    return consume(xs);        // error[E051]: can't transfer a borrowed value
}
```

## Fix

Pass a value you own — e.g. a fresh construction:

```
function g(): i32 {
    return consume([1, 2]);    // fresh array → owned, transfers fine
}
```

…or thread ownership through, making the caller `own` it too:

```
function f(own xs: i32[]): i32 {   // now f owns xs
    return consume(xs);            // transfer OK (xs is consumed exactly once)
}
```

If the callee only needs to *read* the value, drop the `own` on its
parameter so it borrows instead — then any value, owned or borrowed,
can be passed.
