# E039 — `len` builtin error

The built-in `len(x)` function has two failure modes:

- **Wrong arity.** `len()` or `len(x, y)` reject — exactly
  one argument required.
- **Unsupported argument type.** `len(42)` rejects — only
  strings, arrays, and slices have a length to report.

## Examples

```
function main(): i32 {
    return len();                 // error[E039]: len expects 1 argument, got 0
}

function main2(): i32 {
    var n: i32 = 42;
    return len(n);                // error[E039]: len: expected string, array, or slice, got i32
}
```

## Fix

Pass exactly one supported value.

```
function main(): i32 {
    var xs: i32[] = [1, 2, 3];
    return len(xs);               // 3
}
```
