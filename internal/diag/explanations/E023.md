# E023 — Unknown enum

A `let-else`, `if-let`, `match`, or `switch` referenced an
enum type by name that the checker doesn't know about.
Typically a typo or a missing import.

## Example

```
match (s) {
    Statuus.Ok => { return 1; },   // error[E023]: unknown enum "Statuus"
}
```

## Fix

Correct the spelling (the checker emits suggestions when the
name is close to a known one), or declare / import the
enum.

```
enum Status { Ok, Err }

match (s) {
    Status.Ok => { return 1; },
}
```

## Built-in enums

The compiler auto-injects `Option`, `Result`, `IoError`,
`JsonValue` — those need no import.

## See also

- E001 (undefined identifier) — the same shape but for any
  name, not specifically an enum-context lookup.
- E014 (variant not part of enum) — when the enum IS found
  but the variant name doesn't match.
