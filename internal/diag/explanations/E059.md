# E059 — `as?` downcast requires a `dyn Trait` value

The `as?` operator narrows a trait object (`dyn Trait`) to a concrete type,
yielding an `Option` of that type. Its left operand must therefore be a
`dyn Trait` value — there is nothing to downcast *from* when the left side is
already a concrete type, a scalar, or `string`. See `docs/DYN-TRAITS.md`.

## What is rejected

```
var x: i32 = 5;
var y = x as? Circle;        // error[E059]: left of `as?` is i32, not a `dyn Trait`
```

## Fixing it

Downcast a value whose static type is `dyn Trait`:

```
function area_of(s: dyn Shape): i32 {
    match (s as? Circle) {
        Some(c) => { return c.r * c.r * 3; },
        None    => { return 0; },
    }
}
```

If you have a concrete value and want a `dyn Trait`, widen it first (pass it
where a `dyn Trait` is expected), then downcast.
