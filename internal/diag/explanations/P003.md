# P003 — Left-hand side of assignment is not assignable

An assignment `LHS = expr;` where the left-hand side isn't
a valid target for assignment. Assignable shapes:

- Variables: `x = ...`
- Struct fields: `p.x = ...`
- Tuple elements: `t.0 = ...`
- Array elements: `arr[i] = ...`

Anything else (function call result, literal, arbitrary
expression) rejects.

## Examples

```
function main(): i32 {
    foo() = 1;          // error[P003]: left-hand side of assignment is not assignable
    42 = "x";           // error[P003]: ...
    (a + b) = 5;        // error[P003]: ...
    return 0;
}
```

## Fix

Assign to a real storage location:

```
function main(): i32 {
    var x: i32 = foo();
    x = 1;
    return x;
}
```

## Why

Fern's value semantics mean assigning to a temporary doesn't
do anything observable; the parser rejects the shape rather
than silently dropping the assignment.

- E013 (variable already declared) — when the LHS IS valid

- E001 (undefined identifier) — when the LHS name doesn't
  resolve to any declaration.
