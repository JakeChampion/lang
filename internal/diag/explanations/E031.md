# E031 — Match arms have incompatible types

A `match` expression's arms each produce a value, and those
values must all share the same type. The checker fires E031
when the arms disagree.

## Example

```
function f(s: Status): string {
    return match (s) {
        Ok => 1,        // i32
        Err => "err",   // string  → error[E031]: match-expression arms differ: i32 vs string
    };
}
```

## Fix

Align every arm's value type. Use casts where the underlying
types can be unified.

```
function f(s: Status): string {
    return match (s) {
        Ok => "ok",
        Err => "err",
    };
}
```

If the natural types genuinely differ, lift the value into
a wider type (typically an enum that wraps both):

```
enum Either { Num(i32), Text(string) }

function f(s: Status): Either {
    return match (s) {
        Ok => Num(1),
        Err => Text("err"),
    };
}
```

## When this fires (not)

A `match` STATEMENT (whose arms each return / break / loop
out, with no falling-through value) doesn't trigger E031 —
no expression-shape result type. Only the
`var x = match (...) { ... };` form does.
