# E038 — Call error

Two related call-site errors:

- **Calling a non-function value.** `x(args)` where `x`
  isn't a function-typed value.
- **Argument type mismatch.** A call argument's type
  doesn't match the corresponding parameter's declared
  type.

## Examples

```
function add(a: i32, b: i32): i32 { return a + b; }

function main(): i32 {
    var n: i32 = 5;
    return n(1, 2);            // error[E038]: calling non-function value of type i32
}

function main2(): i32 {
    return add(1, "two");      // error[E038]: argument 2: expected i32, got string
}
```

## Fix

For non-function calls: check that the name you're calling
actually refers to a function. Common bug: a variable
shadows a function of the same name.

For argument-type mismatches: cast the argument or change
the callee's signature.

```
function main(): i32 {
    return add(1, 2);
}
```

## Generic functions

Generic functions infer type arguments from the call's
arguments. If inference fails because the arguments don't
pin every type parameter, you'll see E040 rather than E038.
E038 fires once arity + type-parameter resolution succeed
and the per-argument check still finds a mismatch.

## See also

- E004 (wrong number of arguments) — fires before the
  per-argument E038 check.
- E002 (type mismatch) — broader category.
