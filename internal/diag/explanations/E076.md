# E076 — default argument is not a constant expression

A parameter's default value must be a **constant expression**: a literal, or
arithmetic / comparison / logical operations over literals. It may not read
any other name — not another parameter, not a local, not a module function.

## Why

Defaults are filled in by copying the expression into each **call site**
before type-checking (`internal/defaultargs`). A name inside the expression
is therefore resolved where it was pasted — in the caller — rather than in
the function that declared it.

That made two things go silently wrong:

```
function f(a: i32, b: i32 = a * 2): i32 { return a + b; }

function main(): i32 {
    var a: i32 = 100;
    return f(1);          // was 201: `a * 2` read main's `a`, not f's
}
```

and a default naming a module-level function picked up a caller local of the
same name instead, reporting the mismatch against the *callee's* declaration.

Requiring the expression to carry no free names removes the question
entirely: there is nothing left to resolve in the wrong scope.

## What is accepted

```
function listen(port: i32, backlog: i32 = 128): i32 { … }
function greet(name: string, greeting: string = "hello"): string { … }
function scale(x: i32, factor: i32 = 2 * 3): i32 { … }
```

Top-level `const` declarations are folded to literals before defaults are
resolved, so a const reference is fine:

```
const BACKLOG: i32 = 128;
function listen(port: i32, backlog: i32 = BACKLOG): i32 { … }
```

## What is rejected

```
function f(a: i32, b: i32 = a * 2): i32 { … }      // reads a parameter
function g(n: i32 = default_size()): i32 { … }     // reads a function
```

## How to fix it

Pass the value explicitly at the call site, or compute it in the body from a
sentinel:

```
function f(a: i32, b: i32 = 0): i32 {
    var actual: i32 = if (b == 0) { a * 2 } else { b };
    return a + actual;
}
```
