# E007 — Duplicate field

A field name appeared twice inside the same struct declaration
or struct literal.

## Example

```
struct Point { x: i32, y: i32, x: i64 }   // error[E007]: duplicate field "x" in struct Point

function main(): i32 {
    var p = Point { x: 1, y: 2, x: 3 };   // error[E007]: duplicate field "x" in struct literal
    return p.y;
}
```

## Fix

Pick distinct names for each field.

```
struct Point { x: i32, y: i32, w: i64 }
```

## Why no aliases

Fern doesn't support field aliases (multiple names for the
same storage). Each field is its own offset; the checker
needs unique names to look up the right one. Aliases would
also obscure the storage cost — preferable to keep field
counts visible at the declaration.
