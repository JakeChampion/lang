# E025 — `switch` case error

A `switch` statement either dispatched on a float (which lang
rejects — floating-point equality isn't a robust comparison)
or had a `case` value whose type didn't match the scrutinee.

## Example

```
function f(x: f32): i32 {
    switch (x) {                          // error[E025]: switch on float values is not supported
        case 1.0: { return 1; }
        default: { return 0; }
    }
}

function g(n: i32): i32 {
    switch (n) {
        case "hello": { return 1; }       // error[E025]: case value type string, expected i32
    }
    return 0;
}
```

## Fix

For float scrutinees: use `if (x == EPS_TARGET)` with an
epsilon comparison instead of switch.

For mismatched case types: align the case literals with the
scrutinee type.

```
function g(n: i32): i32 {
    switch (n) {
        case 1: { return 1; }
        case 2: { return 2; }
        default: { return 0; }
    }
}
```

## Why no float-switch

Floating-point equality isn't a robust dispatch primitive —
0.1 + 0.2 != 0.3 surprises every new user. Lang rejects the
shape outright; intentional float comparisons (range checks,
nearest-bucket dispatch) belong in `if` ladders where the
comparison logic is explicit.
