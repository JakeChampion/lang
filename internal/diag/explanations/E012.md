# E012 — `return` without value in a non-void function

The function declared a return type (e.g. `i32`) but a
`return;` statement omitted the value. Fern requires every
non-void return to carry an expression of the declared type.

## Example

```
function f(n: i32): i32 {
    if (n < 0) {
        return;   // error[E012]: return without value in function returning i32
    }
    return n;
}
```

## Fix

Either supply a value, or change the function's return type
to void (omit the type annotation after `:`).

```
function f(n: i32): i32 {
    if (n < 0) {
        return 0;
    }
    return n;
}
```

Void functions accept `return;` with no value:

```
function log_if_neg(n: i32) {
    if (n < 0) {
        print("negative");
        return;
    }
}
```
