# E024 — Tuple destructure error

A tuple destructuring binding (`var (a, b, c) = expr;`)
either:

- **Source isn't a tuple.** The right-hand side produced
  a non-tuple type, so there's nothing to destructure.
- **Arity mismatch.** The number of names on the left
  doesn't match the tuple's element count.

## Example

```
function pair(): (i32, i32) { return (1, 2); }

function main(): i32 {
    var (a, b, c) = pair();   // error[E024]: tuple has 2 elements, but 3 names given
    return a + b;
}
```

## Fix

Match the name count to the tuple's element count:

```
function main(): i32 {
    var (a, b) = pair();
    return a + b;
}
```

For "source isn't a tuple":

```
function not_tuple(): i32 { return 1; }

function main(): i32 {
    var (a, b) = not_tuple();   // error[E024]: tuple destructure needs a tuple expression, got i32
    return a;
}
```

Either return a tuple, or use a single-variable binding:

```
function main(): i32 {
    var a: i32 = not_tuple();
    return a;
}
```
