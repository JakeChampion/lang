# E060 — invalid `as?` downcast target

The target of an `as?` downcast must be a concrete `struct` or `enum` type
that **implements the trait** of the `dyn Trait` value being narrowed. This
error fires when the target is not a concrete struct / enum (e.g. a primitive
or `string`), or is one that does not implement the source trait — in which
case the downcast could never succeed. See `docs/DYN-TRAITS.md`.

## What is rejected

```
// `Square` does not implement `Shape`
var s: dyn Shape = Circle { r: 2 };
var x = s as? Square;        // error[E060]: Square does not implement Shape
var y = s as? i32;           // error[E060]: target must be a concrete struct/enum
```

## Fixing it

Downcast to a concrete type that implements the trait:

```
var x = s as? Circle;        // Circle implements Shape → Option[Circle]
```

If the type *should* be downcastable, add the missing `impl Shape for Square`.
