# E022 — `let-else` / `if-let` source error

The source expression in a `let-else` (`var x else { ... } = expr;`)
or `if-let` (`if let x = expr { ... }`) construct didn't
satisfy the form's requirements.

Two specific forms surface as E022:

- **Source must be an enum value.** `let-else` and `if-let`
  destructure enum variants (typically `Option` / `Result`);
  the source expression must produce an enum type.
- **`let-else` else branch must diverge.** The else branch
  must end with `return`, `break`, or `continue` — falling
  out of the else block is not allowed (the binding wouldn't
  be defined past the let-else).

## Example

```
function f(x: i32): i32 {
    var n else { print("not a number"); } = x;   // error[E022]: let-else source must be an enum value, got i32
    return n;
}
```

## Fix — source-must-be-enum

Wrap the source in an enum, typically `Option`:

```
function f(opt: Option[i32]): i32 {
    var n else { return 0; } = opt;
    return n;
}
```

## Fix — else-must-diverge

Add a `return` / `break` / `continue` to the else branch:

```
function f(opt: Option[i32]): i32 {
    var n else {
        print("absent");
        return 0;             // diverge
    } = opt;
    return n;
}
```
