# E057 — `Cell[T]` element type is not allowed

A `Cell[T]` is the one mutable cell in the language. To keep the
immutable-data guarantee that makes reference cycles unconstructible (so
Perceus reference counting needs no cycle collector — `docs/CELL-TYPE-PLAN.md`),
a cell's element type must be **cycle-free**: a scalar (`i32` / `i64` / `f64`
/ `bool`) or `string`. A composite or reference element (struct, enum, array,
tuple, or another `Cell`) could be made to point back at the cell's owner and
close a cycle, which the model forbids.

## What is rejected

```
struct Node { next: Cell[Node] }   // error[E057]: a Cell over a reference type could form a cycle
var c = cell_new([1, 2, 3]);       // error[E057]: array element is not cycle-free
```

## What is allowed

```
var counter = cell_new(0);         // Cell[i32]
var name = cell_new("anon");       // Cell[string]
```

## Fixing it

Store a scalar or string in the cell — for example a key / index / handle that
*refers* to a value held elsewhere, rather than the composite value itself.
