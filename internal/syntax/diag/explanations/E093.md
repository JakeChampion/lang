# E093 — a `const` initializer is not a constant expression

A `const` is evaluated when the program is compiled, so its initializer may
use only literals, earlier consts, and arithmetic, comparison and logical
operations on them, and it must evaluate: a `/` or `%` by zero has no value.
The error is at the `const`:

```
function f(): i32 {
    return 1;
}

const A: i32 = f();           // error[E093]: const A: expression is not a constant
const B: i32 = C + 1;         // error[E093]: const B: "C" is not a constant (must reference an earlier `const` declaration)
const C: i32 = 2;
const D: i32 = 6 +| 2;        // error[E093]: const D: operator `+|` not allowed in integer constant expressions
const E: i32 = 10 / (C - 2);  // error[E093]: const E: division by zero in constant expression
```

Fixes:

- Compute a value that needs a call at run time, in a function, rather than
  in a `const`.
- Declare a const before the consts that use it.
- Check a divisor that can be zero in a function, where `x / 0` is `0`.
