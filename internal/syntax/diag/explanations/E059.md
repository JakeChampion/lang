# E059 — `as?` requires a `dyn Trait` value or an integer

The `as?` operator yields an `Option`. It narrows a trait object (`dyn Trait`)
to a concrete type, or converts an integer to another integer type when the
value fits (`300 as? u8` is `None`). Any other left operand — a struct, a
float, a `string` — has nothing for `as?` to do. See `docs/DYN-TRAITS.md`.

## What is rejected

```
let x: string = "5";
let y = x as? Circle;        // error[E059]: left of `as?` is string, neither a `dyn Trait` nor an integer
```

## Fixing it

Downcast a value whose static type is `dyn Trait`:

```
function area_of(s: dyn Shape): i32 {
    match (s as? Circle) {
        Some(c) => { return c.r * c.r * 3; },
        None    => { return 0; },
    }
}
```

If you have a concrete value and want a `dyn Trait`, widen it first (pass it
where a `dyn Trait` is expected), then downcast.
