# E016 — Union declaration error

The union declaration is malformed in one of these ways:

- **Name collides with a struct of the same name.** Fern's
  type namespace is shared between structs, enums, and unions
  — each must be unique.
- **Name collides with an enum of the same name.** Same
  rule.
- **Duplicate member.** A union member appeared twice in the
  decl (`type Either = A | B | A;`). Pick one.
- **Member doesn't name a struct in scope.** Unions list
  struct types — non-struct members aren't supported.
- **Member's type arguments don't match the struct.** A
  generic struct member must be given its arguments, and a
  plain struct member must not be given any. The arguments
  can be concrete (`type Tree = Leaf[i32] | Lit;`) or the
  union's own parameters (`type Tree[T] = Leaf[T] | Node[T];`).

  Note that two instantiations of the SAME struct
  (`type X = Box[i32] | Box[string];`) is still rejected, as a
  duplicate member: the synthesised variant is named after the
  struct, so both would be `Box`. Wrap one in its own struct
  if you need both in one union.

## Example

```
struct Either { value: i32 }
type Either = Foo | Bar;   // error[E016]: union "Either" collides with a struct of the same name
```

## Fix

Rename one of the colliding declarations.

```
struct EitherValue { value: i32 }
type Either = Foo | Bar;
```
