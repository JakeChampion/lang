# E092 — a literate document does not tangle

A literate document (`.fern.md`) is tangled into Fern source before it is
checked. The document is refused when it cannot be tangled:

- **An undefined chunk.** A `<<name>>` reference names no `<<name>>=` block.
  The error is at the reference.
- **A cyclic chunk.** A chunk reaches itself through its references. The
  error is at the chunk's first header.
- **No root.** A single-file document has no `<<*>>=` block, or
  `-tangle -chunk NAME` names a chunk that no block defines.
- **No compile entry.** A multi-file document has no `file=` blocks, or
  several are marked `entry`, or several files are written and none is
  marked `entry`.

## Example

````
```fern
<<*>>=
<<main>>        // error[E092]: literate: reference to undefined chunk "<<main>>"
```
````

Fix: define the chunk the reference names, or correct the reference.
`docs/LITERATE.md` describes the chunk grammar.
