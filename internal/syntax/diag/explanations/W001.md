# W001 — a `todo` stub remains

`todo;` and `todo("message");` stand in for code not written yet. The
program still compiles, and reaching a stub at run time exits with status
101. Each stub left in a program that otherwise checks is reported at the
stub, so none ships unnoticed:

```
function parse(s: string): i32 {
    todo("parse the header");   // warning[W001]: `todo` stub remaining
}

function main(): i32 {
    return 0;
}
```

The warning is reported only when the program has no errors.

Fix: write the code the stub stands for, and delete the stub.
