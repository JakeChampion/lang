# E022 — `let-else` / `if-let` source error

The source expression in a `let-else` (`let Some(x) = expr else { ... };`)
or `if-let` (`if let Some(x) = expr { ... }`) construct didn't
satisfy the form's requirements.

Two specific forms surface as E022:

- **Source must be an enum value.** `let-else` and `if-let`
  destructure enum variants (typically `Option` / `Result`);
  the source expression must produce an enum type.
- **`let-else` else branch must diverge.** The else branch
  must end with `return`, `break`, `continue`, a call to
  `exit`, or an infinite loop — falling out of the else block
  is not allowed (the binding wouldn't be defined past the
  let-else).

## Example

```
function f(x: i32): i32 {
    let Some(n) = x else { return 0; };   // error[E022]: let-else source must be an enum value, got i32
    return n;
}
```

## Fix — source-must-be-enum

Wrap the source in an enum, typically `Option`:

```
function f(opt: Option[i32]): i32 {
    let Some(n) = opt else { return 0; };
    return n;
}
```

## Fix — else-must-diverge

End the else branch with `return` / `break` / `continue` / `exit`:

```
function f(opt: Option[i32]): i32 {
    let Some(n) = opt else {
        eprint("absent");
        exit(1);              // diverge
    };
    return n;
}
```
