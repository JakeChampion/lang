# E057: `Cell[T]` element type is not allowed

A `Cell[T]` is the one mutable slot in the language. Everything else is
immutable after construction, so a value can only point at values that
existed before it: reference cycles cannot be built, and reference counting
needs no cycle collector. A cell is where that could break: if a cell's
element could hold the cell itself, `set` could close a loop.

So a cell's element must be built only from:

- scalars (integers, floats, `boolean`, `char`) and `string`;
- arrays `T[]`, tuples, `Map[K, V]`;
- structs and enums whose fields and payloads are themselves built this way.
  Recursive types (`enum Tree { Leaf(i32), Node(Tree[]) }`) are fine.

Those values are trees, so none of them can reach a cell. The element is
refused when any part of it is:

- a function type: a closure can capture the cell it is stored in;
- a `Cell`, directly or inside the element: a second slot that can point back;
- `dyn Trait`, which can hide either of those;
- a type parameter, which could be instantiated with either of those;
- a borrowed view (`str`, `[T]`), which the cell would outlive;
- a resource handle or a `MapIter` cursor.

The check runs on every `Cell[...]` annotation and on every `cell_new(v)`.

## What is rejected

```
struct Handler { run: () => i32 }
let c = cell_new(Handler { run: () => 1 });   // E057: Handler contains () => i32
function f(c: Cell[Cell[i32]]) {}             // E057: Cell[i32]
function mk[T](x: T): Cell[T] { return cell_new(x); }   // E057: T
```

## What is allowed

```
let hits: Cell[Map[string, i32]] = cell_new(map_new(8));
let log: Cell[string[]] = cell_new([]);
let session = cell_new(Session { user: "", visits: 0, last: None });
```

A cell read is a snapshot: `get()` returns the value, and a later `set`
replaces the slot without changing what an earlier `get()` returned.

## Fixing it

Keep the function, cell or view outside the cell and store data that refers
to it instead: a key, an index or an enum tag that selects the behaviour.
For a generic container, name the concrete element type at the cell.
