# E006 — Top-level declaration redeclared

A function, struct, or enum was declared twice in the same
program. Fern doesn't support overloading or shadowing at the
top level.

## Example

```
struct Point { x: i32, y: i32 }
struct Point { x: f32, y: f32 }   // error[E006]: struct "Point" redeclared
```

## Fix

Either rename one of the declarations, or merge their
behaviours into a single declaration. For functions, Fern's
position-based dispatch doesn't permit overloading by argument
type — give the variants distinct names (`add_i32` /
`add_f32`).

```
struct PointI { x: i32, y: i32 }
struct PointF { x: f32, y: f32 }
```

## See also

- E007 (duplicate field) — the same shape at the field level
  inside a struct decl.
- E010 (reserved name) — collision with a built-in.
