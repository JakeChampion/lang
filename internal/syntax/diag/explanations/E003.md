# E003 — Cannot assign value to variable of different type

A value does not have the declared type of the place that holds it.
The checker reports E003 for:

- a `let x: T = expr;` initializer whose type is not `T`
- a reassignment `x = expr;`
- an assignment to a field or an element
- the base of a struct update `T { ...base, f: v }` that is not a `T`

A `return` value or a `const` initializer of the wrong type is E002.
An argument of the wrong type is E038.

## Example

```
function f() {
    let x: i32 = "oops";   // error[E003]: variable "x": expected i32, got string
}
```

## Fix

Give `x` the type of the value, or change the value to the declared
type. For a number, use an explicit `as` cast where the conversion can
lose information.

```
function f() {
    let x: string = "oops";
}
```

## See also

- E002 (type mismatch): a `return` value or a `const` initializer.
- E038: a call argument.
