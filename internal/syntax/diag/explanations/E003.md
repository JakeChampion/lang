# E003 — Cannot assign value to variable of different type

A reassignment `x = expr;` produced a value whose type doesn't
match `x`'s declared type. Distinct from E002 (return /
initializer mismatch) — surfaces specifically on the
left-hand-side of `=`.

## Example

```
function f() {
    let x: i32 = 1;
    x = "oops";   // error[E003]: variable "x": expected i32, got string
}
```

## Fix

Either give `x` a wider type at declaration, or coerce `expr`
to fit.

```
function f() {
    let x: string = "oops";
}
```
