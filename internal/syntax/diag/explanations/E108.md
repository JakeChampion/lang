# E108 — a nested function captures a name that is declared too late

Nested functions that call each other are one group. The group
is in scope from the declaration of its first function. From
that point, the first function can call each other function
of the group. A function of the group thus cannot capture a
name that the block declares after the first function. At a
call from the first function, that name possibly has no value.

The name can be a local, a destructured local, or a nested
function that is not in the group.

## Example

```
function main(): i32 {
    function a(n: i32): i32 {
        if (n == 0) { return 0; }
        return b(n - 1);
    }
    let k = 5;
    // error[E108]: nested function "b" captures "k", but "a"
    // can call "b" before the declaration of "k": declare
    // "k" before "a"
    function b(n: i32): i32 {
        if (n == 0) { return k; }
        return a(n - 1);
    }
    return a(3);
}
```

## Fix

Declare the name before the first function of the group.

```
function main(): i32 {
    let k = 5;
    function a(n: i32): i32 {
        if (n == 0) { return 0; }
        return b(n - 1);
    }
    function b(n: i32): i32 {
        if (n == 0) { return k; }
        return a(n - 1);
    }
    return a(3);
}
```

As an alternative, give the value to the functions as a
parameter.
