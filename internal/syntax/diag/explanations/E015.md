# E015 — Variant payload count mismatch

A `match` arm (or `if let` / `let else`) bound a different
number of payloads than the variant declares. The checker
expects exactly one binding name per payload type.

## Example

```
enum Shape {
    Circle(f64),
    Rect(f64, f64),
}

function area(s: Shape): f64 {
    match (s) {
        Circle(r) => { return r * r; },
        Rect(w) => { return w; },   // error[E015]: variant Rect has 2 payload(s), got 1 binding(s)
    }
}
```

## Fix

Bind all payloads. Use `_` to ignore unused ones explicitly.

```
function area(s: Shape): f64 {
    match (s) {
        Circle(r) => { return r * r; },
        Rect(w, h) => { return w * h; },
    }
}
```

For variants with no payloads, omit the parentheses entirely:

```
enum Maybe { Yes, No(string) }

match (m) {
    Yes => { print("yes"); },        // no `()` for empty payload
    No(reason) => { print(reason); }, // one binding for one payload
}
```

## A payload-less variant's name used as a binder

E015 also fires when a nested position is spelled with the name of a
payload-less variant. At the top level of an arm that name is a tag test, but
one level in it parses as a **binder** — so the arm matches every value of that
slot instead of testing the variant the spelling suggests.

```
enum Res { Ok2(i32), Err2 }
enum Nest { Wrap(Res), Bare }

match (w) {
    Wrap(Err2) => { return 9; },  // error[E015]: Err2 is a payload-less variant of enum Res
    _ => { return 1; },
}
```

In a payload slot the fix is the empty-paren spelling, which is unambiguous:

```
match (w) {
    Wrap(Err2()) => { return 9; },
    _ => { return 1; },
}
```

The same reading applies to a **tuple element**, where `(B, y)` binds `B` to
every value of the first element:

```
enum E { A(i32), B }

match (t) { (B, y) => { return 100 + y; } }  // error[E015]: matches every value
```

The fix is the same empty-paren spelling — a tuple element takes a variant
sub-pattern, with payload binders where the variant has payloads:

```
match (t) {
    (B(), y) => { return 100 + y; },
    (A(n), y) => { return n + y; },
    _ => { return 0; },
}
```
