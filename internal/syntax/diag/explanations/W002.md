# W002 — an ungoverned dependency reaches a capability

A dependency entry in `fern.toml` without a `capabilities` key is not
enforced yet: what its code reaches is allowed, and each reach is reported
as a warning. The warning is at the dependency's function the call chain
starts from, and carries the chain, each function named as its source
declares it:

```
helper/lib.fern:1:5: warning[W002]: package "helper" reaches 'fs'
(write_file) but no capabilities key governs it: save → write_file; add
capabilities = [...] to its dependency entry in fern.toml (ungoverned
packages will become errors once default-deny lands)
```

Fix: add a `capabilities` list to the dependency's entry in your
`fern.toml`. With the key present, a reach outside the list is `E070`
(`fern -explain E070` has the rules and the other fixes):

```toml
[dependencies]
helper = { path = "../helper", capabilities = ["fs"] }
```
