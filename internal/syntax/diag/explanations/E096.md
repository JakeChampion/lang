# E096 — a `Vec[N, T]` that names no lane type

`Vec[N, T]` is the second spelling of a lane type. `Vec[2, f64]` is `f64x2`
and `Vec[4, f32]` is `f32x4`. The portable tier has a lane type only where
N lanes of T fill 128 bits, so every other pair is refused.

A generic `Vec[N, T]` names a type parameter. It is refused when no pair of
the table can fit it, as `Vec[3, T]` cannot. The rule is the same for the
type of an impl: `impl[T] Total for Vec[3, T]` is refused at the impl.

## What is rejected

```
function f(v: Vec[3, f64]): i32 {   // error[E096]: Vec[3, f64] names no lane type: the portable tier has Vec[2, f64] and Vec[4, f32]
    return 0;
}
```

## Fixing it

Write one of the two pairs, or let a const parameter take the lane count:

```
function f(v: Vec[2, f64]): i32 {
    return 0;
}

function g[const N: i32, T](v: Vec[N, T]): i32 {
    return N;
}
```
