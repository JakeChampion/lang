# E010 — Reserved built-in name

A user declaration tried to use a name that the compiler
reserves for a built-in type, such as `Option`, `Result`,
`IoError`, `Map`, `HttpRequest`, `Span` or `Duration`.

The runtime helpers and IR pair-form lowering hard-code these
types' shapes (variant order, field offsets). Letting a user
override one would miscompile silently — `enum Option { None,
Some(T) }` (note: swapped order) would diverge between
pair-form and heap-form returns.

## Example

```
struct HttpRequest { method: string }   // error[E010]: struct "HttpRequest" is a reserved built-in name and cannot be redeclared
```

## Fix

Pick a different name. The built-ins are scoped so user
declarations CAN refer to them; they just can't shadow.

```
struct MyRequest { method: string }
```

## Full reserved list

`ast.ReservedTypeNames()` in `internal/syntax/ast/ast.go` is the
list. `TestReservedTypeNamesAreTheBuiltinDecls` pins it to the
checker's built-in declarations, so a new built-in type is
reserved as soon as it ships.
