# E081 — Missing return type

A named function was declared without a return type. Every named
function writes its return type, `: void` when it returns nothing. A
signature is the part of a function its callers read, so it is written
rather than inferred from the body.

## Example

```
function greet() {          // error[E081]: missing return type on function "greet"
    return "hi";
}
function main(): i32 {
    print(greet());
    return 0;
}
```

## Fix

Declare the type the function returns:

```
function greet(): string {
    return "hi";
}
```

and `: void` for a function that returns nothing:

```
function log(msg: string): void {
    eprint(msg);
}
```

Lambdas are not affected: `(x: i32) => x * 2` takes its return type
from its body.

A `const` written without a type takes the type of its value. When the
value has no type the compiler can determine, the same code is reported
for the `const`; write its type out (`const LIMIT: i64 = …;`).
