# E106 — a type has too many parts

The type of a call or of a tuple has a limit of 4096 parts. A
part is one type inside the type: `(i32, (i32, string))` has
five parts.

A generic call that holds its argument two times doubles the
type at each level. Twelve levels are over the limit, and thirty
levels are more than a billion parts. The check of that type
does not end, so the checker stops at the limit.

## Examples

```
function pair[T](x: T): (T, T) {
    return (x, x);
}

function main(): i32 {
    // error[E106]: type has more than 4096 parts
    let x = pair(pair(pair(pair(pair(pair(pair(pair(pair(pair(pair(pair(1))))))))))));
    return 0;
}
```

## Fix

Hand-written code does not reach this limit. The usual cause is
generated code. A second cause is a function that returns its
argument in a larger type and calls itself on the result.

- Hold the repeated value one time, and read it where it is
  needed.
- Use an array for values of one type: `T[]` has two parts for
  any number of elements.
