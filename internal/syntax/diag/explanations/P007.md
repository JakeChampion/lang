# P007 — a method declares a receiver type parameter again

A receiver introduces the type parameters that its type names. In
`function (b: Box[T]) get(): T`, the receiver introduces `T`. The method
does not declare `T` in its own list.

The method's own list declares only the type parameters that the
receiver does not name. A name in that list that also occurs in the
receiver type is P007.

## Example

```
import "core/cmp";

struct Box[T] { v: T }

function (b: Box[T]) get[T](): T {            // error[P007]
    return b.v;
}

function (b: Box[T]) larger[T: cmp.Ord](o: T): T {   // error[P007]
    if (b.v.cmp(o) > 0) {
        return b.v;
    }
    return o;
}
```

## Fix

Remove the name from the method's list. To bound the parameter, write the
bound in the receiver type, where the name occurs first:

```
function (b: Box[T]) get(): T {
    return b.v;
}

function (b: Box[T: cmp.Ord]) larger(o: T): T {
    if (b.v.cmp(o) > 0) {
        return b.v;
    }
    return o;
}
```

A bound can open a type argument, a slice element or a group. To bound
the element of an array receiver, write the element as a group:

```
function (xs: (T: cmp.Ord)[]) peak(): T { ... }
function (xs: [T: cmp.Eq]) first(): T { ... }
function (m: OrdMap[K: cmp.Ord, V]) insert(k: K, v: V): OrdMap[K, V] { ... }
```

The method can still declare a type parameter that only it uses:

```
function (m: Map[K, V]) fold[A](init: A, f: (A, K, V) => A): A { ... }
```

One rule gives one form. Before P007, some methods declared a receiver
parameter again and some did not. The method's list was the only place
for a bound.
