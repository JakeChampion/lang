# E014 — Variant not part of enum

A `match` arm, `if let`, or `let else` referenced a variant
name that isn't declared on the enum's scrutinee.

## Example

```
enum Color { Red, Green, Blue }

function name_of(c: Color): string {
    match (c) {
        Red => { return "red"; },
        Green => { return "green"; },
        Purple => { return "purple"; },   // error[E014]: variant "Purple" is not part of enum Color
    }
}
```

## Fix

Either correct the variant name (the checker emits a "did
you mean Red?" suggestion when names are close) or add the
variant to the enum decl.

```
enum Color { Red, Green, Blue, Purple }
```

## See also

- E015 (variant payload count mismatch) — same enum, but
  the variant exists and the payload binding count is off.
- E001 (undefined identifier) — when the typo is on the
  scrutinee itself, not the variant.
