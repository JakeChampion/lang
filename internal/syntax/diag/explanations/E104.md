# E104 — an `@early` hook of the wrong shape, a second hook, or a target without a reset entry

An `@early` function is the early-setup hook of a kernel image. The reset
entry calls it once, before the heap starts. Then early hardware setup, such
as a clock, a power domain or a page-table change, is Fern code, not
assembler.

When the hook runs, the stack exists, `.bss` is clear and the translation of
the reset entry is on. On arm64 the vector table is set. On x86-64 the IDT is
loaded. The heap does not exist yet.

The rules are:

- The hook takes no parameters and returns `void`.
- A program has at most one hook.
- Only `-target arm64-kernel` and `-target x86-64-kernel` have a reset entry.

`@early` implies `@norc`, so E102 also applies to the body of the hook: it
allocates nothing and does no RC operation.

```
@early
function setup(level: i32): void {
    // error[E104]: `@early` function "setup" must take no parameters and return void
}
```

## Fix

Give the hook no parameters, and keep one hook for each program. A hook can
write its results to memory or to a system register. `main` can then read
them.

```
@early
function setup(): void {
    unsafe {
        __sysreg_write("tpidr_el1", 1i64);
    }
}
```
