# E094 — an embedded asset the compiler cannot resolve

`__fern_asset`, `__fern_asset_bytes`, `__fern_assets` and
`__fern_assets_bytes` are replaced, when the program is compiled, by files
from the directory passed with `-embed DIR` (`docs/EMBED.md`). The call is
refused when that cannot be done:

- no `-embed DIR` was passed;
- the name is not a string literal, so it cannot be known at compile time;
- no embedded file has that name;
- the call has the wrong number of arguments;
- the text form names a file that is not valid UTF-8.

```
function main(): i32 {
    let page: string = __fern_asset("index.htm");
    // error[E094]: no embedded asset "index.htm" under assets; did you mean "index.html"?
    return page.len();
}
```

Fixes: pass `-embed DIR`, correct the name, or read a binary file with the
`_bytes` form, which gives a `u8[]`.
