# E083 — a `for` subject is not iterable

`for x in subject` walks:

- an array, a slice or a string, by index;
- a `Map`, by its entries, under a `(key, value)` header;
- a range written in the loop head (`0..n`, `0..=n`), by counting;
- anything implementing `core/iter`'s `Iterator`, by calling `next()` until
  it returns `None` — this covers a range held in a variable, `iter.of(xs)`
  and every adapter chain;
- a value whose `iter()` method returns an `Iterator`, which is how the
  library collections (`OrdMap`, `PMap`, `PVec`, `OrdSet`, `PSet`, `Set`)
  are walked.

The subject here is none of these. The message names its type.

## What is rejected

```
struct Point { x: i32, y: i32 }

function main(): i32 {
    let p: Point = Point { x: 1, y: 2 };
    for c in p {           // error[E083]: cannot iterate over a value of type Point
        print(c);
    }
    return 0;
}
```

A type parameter needs an `Iterator` bound before a generic body can walk it:

```
function each[T](v: T): i32 {
    for x in v { }         // error[E083]: cannot iterate over a value of type T
    return 0;
}
```

## Fixing it

Iterate over something that yields the elements: an array field, or an
Iterator built from one.

```
import "core/iter";

struct Polygon { points: Point[] }

function (p: Polygon) iter(): iter.ArrayIter[Point] {
    return iter.of(p.points);
}
```

With that `iter()` method, `for pt in polygon` walks the points. In a
generic function, bound the parameter: `function each[I: iter.Iterator[i32]](v: I)`.
