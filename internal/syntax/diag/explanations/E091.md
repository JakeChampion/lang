# E091 — an assignment to a name that cannot change

A `const` declaration names a value fixed when the program is compiled, so
an assignment to it is refused: `cannot assign to const A`.

A const parameter (`const N: i32`) is an `i32` value in the body of its
function. Each instance of the function holds its own integer in the place
of `N`. So `N` is a constant and not a place, and an assignment to it is
refused.

The index of a range `for` (`for i in 0..n`) gets the next value at the start
of each turn. An assignment to it in the body changes the values that the
loop visits, so it is refused. A `let` in the body can declare a new `i`, and
an assignment to that `i` is permitted.

## What is rejected

```
function bump[const N: i32](): i32 {
    N = 4;                 // error[E091]: cannot assign to const parameter N: it is the constant its instance is made for
    return N;
}

for i in 0..10 {
    i += 1;                // error[E091]: cannot assign to range index i: the loop sets it on each turn, so use a while loop to change it
}
```

## Fixing it

Copy the value into a local, and change the local:

```
function bump[const N: i32](): i32 {
    let k: i32 = N;
    k = k + 1;
    return k;
}
```

To move the index of a loop, write a `while` loop:

```
let i = 0;
while (i < 10) {
    i += 2;
}
```
