# E099 — a built-in handle built from a literal

A `Reader`, `Writer` or `Dir` owns a descriptor. Only the call that opens
one makes it, and its `close` consumes it. A struct literal of one of these
types is refused, with or without a spread. It makes a second handle for a
descriptor that another handle owns.

```
function main(): i32 {
    let out: Writer = stdout();
    // error[E099]: a Writer cannot be built from a literal: only the call that opens it makes one
    let copy: Writer = Writer { fd: out.fd };
    return copy.fd;
}
```

Fix: pass the handle itself, or open another one. A struct the program
declares with the same name in its own module is its own type.
