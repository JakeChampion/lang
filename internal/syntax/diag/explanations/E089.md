# E089 — a const argument is not an integer literal or a const parameter

A const parameter (`const N: i32`) takes an integer as its argument. The
argument names the instance that the call runs, so the compiler must know
it before the program runs. Two spellings give such an integer:

- An integer literal in any base, with or without `_` separators:
  `filled[4](x)`, `filled[0x10](x)`, `filled[1_000](x)`.
- A const parameter of the function that makes the call: `filled[M](x)`.

A local value, a parameter of the function or an expression such as `k + 1`
is refused. A literal whose value does not fit in an `i32` is refused too.

## What is rejected

```
function filled[const N: i32](x: f64): f64[] {
    let out: f64[] = [];
    while (out.len() < N) {
        out = out.append(x);
    }
    return out;
}

function main(): i32 {
    let k: i32 = 2;
    let a: i32 = filled[k](1.0).len();             // error[E089]: the const argument for N must be an integer literal or a const parameter
    let b: i32 = filled[2147483648](1.0).len();    // error[E089]: the const argument for N must fit in i32
    return a + b;
}
```

## Fixing it

Write the integer, or make the caller generic over it too:

```
function twice[const M: i32](): i32 {
    return filled[M](1.0).len() * 2;
}

function main(): i32 {
    return filled[2](1.0).len() + twice[3]();
}
```

When the count is known only at run time, use an `i32` parameter in place of
the const parameter.
