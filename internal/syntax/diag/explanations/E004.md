# E004 — Wrong number of arguments to a call

The call site passes a different number of arguments than the
function's signature declares.

## Example

```
function add(a: i32, b: i32): i32 { return a + b; }

function main(): i32 {
    return add(1);   // error[E004]: add expects 2 arguments, got 1
}
```

## Fix

Either supply the missing argument or add a default-valued
overload (when Fern grows that surface). Optional-argument
positions need to be declared as `Option[T]` and the call
site passes `Some(v)` / `None`.

```
function main(): i32 {
    return add(1, 2);
}
```
