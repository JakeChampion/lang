# E044 — Captured variable has unsupported type

A closure captured a variable that has no runtime value: the result of a
call to a `void` function, bound to a variable. Every other type can be
captured — scalars, strings, arrays, slices, structs, enums, tuples,
function values, and a value whose type is a generic parameter of the
enclosing function (it is concrete by the time the closure is built).

## Example

```
function log(msg: string): void { print(msg); }

function main(): i32 {
    let done = log("start");
    let f = () => done;   // error[E044]: captured variable "done" has unsupported type void
    return 0;
}
```

## Fix

Do not bind a `void` call's result; call it as a statement.

```
function log(msg: string): void { print(msg); }

function main(): i32 {
    log("start");
    let f = () => 0;
    return f();
}
```
