# E097 — a builtin named as a value

A builtin is lowered at its call site; it has no function value to hand
around. Naming one anywhere but in the callee position of a call (binding
it to a variable, passing it as an argument, returning it) is refused.

```
function main(): i32 {
    // error[E097]: builtin "eprint" can only be called, not used as a value
    let f: (string) => void = eprint;
    f("x");
    return 0;
}
```

Fix: wrap the call in a closure, which is an ordinary function value:
`let f: (string) => void = (s: string): void => eprint(s);`. A local or a
declared function that reuses a builtin's name is the program's own value
and is not refused.
