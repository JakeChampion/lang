# E097 — a builtin reserved for the standard library

Some builtins reach the operating system on behalf of a standard-library
module, and a program uses that module instead. The entropy builtins are the
reserved set: `random_i32` and `random_bytes` read the operating system's
entropy source, and `std/rand` is the one place a program gets randomness
from. Naming either builtin outside the standard library is refused, as a
call and as a function value.

```
import "std/rand";

function main(): i32 {
    // error[E097]: builtin "random_i32" is reserved for the standard library; call rand.next_i32 from "std/rand" instead
    let x: i32 = random_i32();
    let y: i32 = rand.next_i32();
    return x + y;
}
```

Fixes: import `std/rand` and call `rand.next_i32()` in place of
`random_i32()` and `rand.bytes(n)` in place of `random_bytes(n)`. A local
binding with the same name as a reserved builtin is the program's own value
and is not refused.
