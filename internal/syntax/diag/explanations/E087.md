# E087 — a module-qualified name the importing module cannot use

`mod.name` refers to a declaration of an imported module. It is refused when
that module does not let the importer use it:

- **Not exported.** The declaration is not `pub`.
- **Package-scoped.** The declaration is `pub(package)` and the importer is
  outside its package (the tree under the nearest `fern.toml`).
- **Not declared.** The module has no declaration of that name.
- **A method.** The name is a method, which is called on a value, not
  through the module.
- **A variant of a private enum.** The variant's enum is not `pub`.

## Examples

With `lib.fern` holding `function hidden(): i32 { return 1; }`:

```
import "./lib";

function main(): i32 {
    return lib.hidden();  // error[E087]: lib.hidden is not exported (declare it as `pub function hidden …` to make it accessible from other modules)
}
```

## Fix

Declare the name `pub` in the module that owns it, or use a name the module
does export.
