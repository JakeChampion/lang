# E023 — Unknown enum

A `let-else`, `if-let` or `match` has a scrutinee whose type names an
enum that the checker does not know. The checker reports an unknown
type name at its declaration first (E064), so a program normally sees
E064 and not E023.

A misspelt enum name in a pattern is a different error. It is E087,
because the checker reads `Statuus.Ok` as a name qualified by a module
that does not exist.

## Example

```
function f(s: Statuus): i32 {   // error[E064]: cannot find type "Statuus" in this scope
    match (s) {
        Statuus.Ok => { return 1; },
    }
}
```

## Fix

Correct the spelling (the checker emits suggestions when the name is
close to a known one), or declare or import the enum.

```
enum Status { Ok, Err }

function f(s: Status): i32 {
    match (s) {
        Status.Ok => { return 1; },
        Status.Err => { return 0; },
    }
}
```

## Built-in enums

The compiler auto-injects `Option`, `Result`, `IoError`,
`Body` — those need no import. `JsonValue` is std/json's: import
it and write `json.JsonValue`.

## See also

- E001 (undefined identifier) — the same shape but for any
  name, not specifically an enum-context lookup.
- E014 (variant not part of enum) — when the enum IS found
  but the variant name does not match.
