# E017 — Duplicate enum variant

Two variants in the same enum declaration share a name. Fern
requires unique variant names so `match` arms can dispatch
unambiguously and the runtime tag (the variant's position
in the declared order) is well-defined.

## Example

```
enum Status {
    Ok,
    Err(string),
    Ok,        // error[E017]: duplicate variant "Ok" in enum Status
}
```

## Fix

Either pick a different variant name, or merge the duplicate
into the existing entry.

```
enum Status {
    Ok,
    Err(string),
}
```
