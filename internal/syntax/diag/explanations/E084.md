# E084 — `main` has the wrong signature

`main` declared a parameter, or a result that cannot be an exit status.
Every runner calls `main` with no arguments, and the value it returns
becomes the process's exit status: an integer is its low byte (`-1` is
255), a boolean is 1 or 0, and `void` is 0. WASI takes only a status below
126, so on `wasm32-wasi` a larger one exits 1. Any other signature has no
call or no status to give, so it is refused where it is declared.

## Example

```
// error[E084]: main takes no parameters
// error[E084]: main returns an integer, a boolean or void, not string
function main(argv: string[]): string {
    return argv[0];
}
```

## Fix

Read the command line with `args()`, and return a status:

```
function main(): i32 {
    let argv: string[] = args();
    print(argv[0]);
    return 0;
}
```
