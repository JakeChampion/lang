# E088 — a `fern.toml` the loader refuses

A package's manifest is read before any of its modules is checked, and a
manifest the loader cannot read refuses the whole program. The diagnostic
points at the manifest's line:

- **Malformed syntax.** A section header without its `]`, a line that is not
  `key = value`, or a value that is not a quoted string, a number or an
  inline table.
- **An unknown section or key.** `[features]`, `edtion = "…"`, or a
  dependency field such as `capabilites = […]`. A misspelt key is refused
  rather than ignored, so a dependency cannot fall out of capability
  enforcement by a typo.
- **A repeated section or key.** TOML defines each once.
- **An invalid dependency.** An unknown capability, an empty `path`, a `url`
  without its `hash`, or a version that is not `MAJOR.MINOR.PATCH`.
- **No `[package] name`** in a manifest that is not a workspace root. This is
  reported at the `[package]` header, or at line 1 when there is none.

## Examples

```
[package]
name = "app"
[dependencies]
kv = { path = "../kv", capabilities = ["nett"] }
```

```
fern.toml:4:1: error[E088]: dependency "kv": capabilities: unknown capability "nett" (valid capabilities: env, fs, net, random, subprocess, time)
```

## Fix

Correct the manifest line the diagnostic names.
