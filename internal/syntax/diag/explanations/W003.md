# W003 — a literate chunk is defined but never used

A chunk of a literate document (`.fern.md`) is part of the program only
when a tangle root reaches it: the `<<*>>` root, or a `file=` block,
through `<<name>>` references. A chunk that no root reaches is reported at
its first `<<name>>=` header. Compilation still proceeds without it.

````
```fern
<<*>>=
<<body>>
```

```fern
<<bdoy>>=          // warning[W003]: chunk <<bdoy>> is defined but never used
function main(): i32 { return 0; }
```
````

Here the reference and the header disagree, and tangling also stops with
`E092` for the undefined `<<body>>`.

Fix: correct the reference or the header so they name the same chunk, or
delete the chunk.
