# P008 — type parameters before a function name

A function declares its type parameters after its name. A method
declares its own type parameters after its name too, and its receiver
introduces the type parameters that the receiver type names.

A `[...]` list between `function` and the name, or between `function`
and a receiver, is P008.

## Example

```
function [T] id(x: T): T {                        // error[P008]
    return x;
}

enum Opt[T] { Some(T), None }

function [U] (o: Opt[T]) map(f: (T) => U): Opt[U] {   // error[P008]
    return None;
}
```

## Fix

Move the list after the name:

```
function id[T](x: T): T {
    return x;
}

function (o: Opt[T]) map[U](f: (T) => U): Opt[U] {
    return None;
}
```

In a method, the list holds only the type parameters that the receiver
does not name. To bound a receiver type parameter, write the bound in
the receiver, as `(b: Box[T: cmp.Ord])` (see P007).

One rule gives one form. Before P008, the parser also accepted the list
before the name, and the two forms made the same declaration.
