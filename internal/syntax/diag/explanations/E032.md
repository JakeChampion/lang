# E032 — `use` clause inference error

The `use` clause (`use BIND in CALLEE(...)`) couldn't infer
the type of the bound parameter. Several forms:

- **Non-identifier source.** `use x in (a + b)(args)` — the
  callee isn't a named function, so no signature to consult.
  Add an explicit `use x: TYPE in ...`.
- **Callee has no signature.** Same shape, different cause —
  the named function doesn't have a known signature.
- **Callee's last parameter isn't a function.** `use` binds
  the callback parameter; the callee must declare its last
  parameter as a function type.
- **Callback takes no arguments.** `use x in foo(...)` where
  `foo`'s last parameter is `() => T` — nothing to bind.
- **Inference from arguments failed.** The callback's
  parameter type depends on a generic parameter the call
  arguments didn't pin down.

## Example

```
function f(): i32 {
    use x in map_oblique(some_list);   // error[E032]: use: could not infer binding type ...
    return x + 1;
}
```

## Fix

Add an explicit annotation.

```
function f(): i32 {
    use x: i32 in map(some_list);
    return x + 1;
}
```

## See also

- E001 (undefined identifier) — when the callee name itself
  is unknown.
- E004 (wrong arity) — when the callee accepts a different
  number of arguments than the `use` form expects.
