# E002 — Type mismatch

A value does not have the type of the declaration that receives it.
The checker reports E002 for:

- a `return` whose value's type does not match the function's declared
  return type
- a `const` initializer whose type is not the declared type
- a function with no return annotation whose `return` statements give
  types that conflict

A `let` initializer or an assignment of the wrong type is E003. An
argument of the wrong type is E038.

## Example

```
function f(): i32 {
    return true;   // error[E002]: return value: expected i32, got boolean
}
```

## Fix

Change the expression to produce the expected type, or change the
declaration to accept the expression's type. The checker widens an
integer only where no value can change, for example `i32` to `i64`. A
conversion that can lose information needs an explicit cast such as
`as i32`.

```
function f(): boolean {
    return true;
}
```
