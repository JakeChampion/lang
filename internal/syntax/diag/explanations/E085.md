# E085 — a lane value is held inside another value

A lane value (`f64x2`, `f32x4`) is 128 bits that live in a vector register.
It lives only in a local, a parameter or a result, and it crosses only a
direct call. Every other place for a value is an 8-byte slot or a general
register, and neither can hold a lane value.

So these are refused:

- A lane type as the element of an array, a tuple or a map, or as a type
  argument.
- A lane type as the type of a struct field or an enum payload.
- A lane type in a function type.
- A function value that carries a lane value. That is a function with a
  lane parameter or result named as a value. It is also a lambda that takes,
  returns or captures a lane value.

## What is rejected

```
import "std/f64";

struct Holder { v: f64x2 }        // error[E085]: a field or payload of type f64x2 holds a lane value

function twice(v: f64x2): f64x2 {
    return v + v;
}

function main(): i32 {
    let xs: f64x2[] = [];          // error[E085]: f64x2[] holds a lane value inside another type
    let f = twice;                 // error[E085]: function twice takes or returns a lane value and cannot be used as a value
    let c: f64x2 = twice(__f64x2_splat(1.0));
    let g = (x: f64): f64 => x + __f64x2_lane(c, 0);   // error[E085]: a lambda cannot capture "c" of type f64x2
    return 0;
}
```

## Fixing it

Keep the lane value in a local and call the function directly. To store lane
values, store their elements: `__f64x2_with(xs, i, v)` writes the lanes of
`v` into an `f64[]` at `i`, and `__f64x2_load(xs, i)` reads them back.

```
function main(): i32 {
    let xs: f64[] = [0.0, 0.0, 0.0, 0.0];
    let v: f64x2 = twice(__f64x2_splat(1.0));
    xs = __f64x2_with(xs, 2, v);
    let w: f64x2 = __f64x2_load(xs, 2);
    return 0;
}
```
