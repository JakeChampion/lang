# E041 — Operator error

Two related operator errors:

- **Cannot compare incompatible types.** `==` / `!=` /
  `<` / `>` / `<=` / `>=` require both operands to share a
  comparable type. Comparing `i32` with `string` rejects.
- **Unknown binary operator.** The parser accepted an
  operator token that the checker doesn't recognize. This
  is rare and typically signals a checker bug — file an
  issue if you hit it.

An `==`, `!=` or order operator on a struct or an enum needs an impl of
`cmp.Eq` or `cmp.Ord`. Add `@derive(cmp.Eq)` or write the impl. A plain
`eq` or `cmp` method with no impl does not give the operator.

## Example

```
function main(): i32 {
    let a: i32 = 1;
    let b: string = "hi";
    if (a == b) {              // error[E041]: cannot compare i32 with string: both sides of "==" must have the same type
        return 1;
    }
    return 0;
}
```

## Fix

Convert one side to the other's type, or restructure the
comparison.

```
function main(): i32 {
    let a: i32 = 1;
    let b: string = "1";
    if (a.to_string() == b) {
        return 1;
    }
    return 0;
}
```
