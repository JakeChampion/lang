# E028 — Match arm variant already covered

A `match` had two arms for the same enum variant. The second
one is unreachable (the first arm always wins) — the checker
rejects this rather than silently producing dead code.

## Example

```
enum Color { Red, Green, Blue }

match (c) {
    Red => { return "warm"; },
    Green => { return "cool"; },
    Red => { return "still warm"; },   // error[E028]: variant "Red" already covered earlier in this match
    Blue => { return "cool"; },
}
```

## Fix

Merge the duplicate arms (most common case — pick one body),
or change one of the patterns if they were meant to cover
different variants.

```
match (c) {
    Red => { return "warm"; },
    Green => { return "cool"; },
    Blue => { return "cool"; },
}
```

## With guards

Duplicate variant patterns with DIFFERENT guards are allowed
— the second arm runs when the first's guard fails. The
"already covered" check fires only when the second arm has
no guard (or a guard the checker can prove redundant).

```
match (n) {
    x if x < 0 => { return "neg"; },
    x if x > 0 => { return "pos"; },
    x => { return "zero"; },           // catches the remaining x == 0 case
}
```
