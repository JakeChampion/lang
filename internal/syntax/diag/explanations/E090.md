# E090 — an argument has the wrong kind for its parameter

A generic function can take two kinds of parameter. A type parameter (`T`)
takes a type, and a const parameter (`const N: i32`) takes an integer. Each
written argument must have the kind of the parameter in the same position.

## What is rejected

```
function count[const N: i32, T](x: T): i32 {
    return N;
}

function main(): i32 {
    let a: i32 = count[string, string]("a");   // error[E090]: const parameter N takes an integer, not the type string
    let b: i32 = count[3, 4]("a");             // error[E090]: type parameter T takes a type, not the integer 4
    return a + b;
}
```

## Fixing it

Write the arguments in the order of the parameter list. Write an integer for
each const parameter and a type for each type parameter:

```
function main(): i32 {
    return count[3, string]("a");
}
```
