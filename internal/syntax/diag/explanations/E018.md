# E018 — Duplicate function parameter

Two parameters in the same function signature share a name.
Each parameter must have a distinct name so the function
body can refer to each one unambiguously.

## Example

```
function add(x: i32, y: i32, x: i32): i32 {   // error[E018]: duplicate parameter "x"
    return x + y;
}
```

## Fix

Pick distinct names.

```
function add(x: i32, y: i32, z: i32): i32 {
    return x + y + z;
}
```

## Why no aliases

Same reasoning as E007 (duplicate field): aliases obscure
the function's argument count, and the runtime ABI needs
distinct names for parameter slot lookup. Fern prefers
explicit distinct names over shadowing-within-signature.
