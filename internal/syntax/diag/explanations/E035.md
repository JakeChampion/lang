# E035 — Literal pattern error in match

Two related forms:

- **Match on a non-enum value only accepts literal patterns
  or `_`.** When matching on an `i32` / `string` / `f64`,
  arms can't bind variants; only constant literals (`42`,
  `"foo"`) or the wildcard.
- **Literal pattern type doesn't match scrutinee type.** A
  literal pattern (`42`, `"hi"`, `true`) whose type doesn't
  align with the scrutinee.

## Example

```
function f(n: i32): string {
    return match (n) {
        Ok => "yes",     // error[E035]: match on non-enum value `i32` only accepts literal patterns or `_`
        _ => "no",
    };
}

function g(s: string): i32 {
    return match (s) {
        42 => 1,         // error[E035]: literal pattern of type i32 does not match scrutinee type string
        _ => 0,
    };
}
```

## Fix

Align the patterns with the scrutinee type.

```
function f(n: i32): string {
    return match (n) {
        0 => "zero",
        _ => "other",
    };
}
```
