# E035 — Literal pattern error in match

Two related forms:

- **Match on a non-enum value only accepts literal patterns,
  a binding name, or `_`.** A match on an `i32`, `string` or
  `f64` has no variants to name. An arm is a constant literal
  (`42`, `"foo"`), a bare name that binds the value
  (`n when n > 100`), or the wildcard.
- **Literal pattern type does not match scrutinee type.** A
  literal pattern (`42`, `"hi"`, `true`) whose type does not
  align with the scrutinee.

## Example

```
enum Answer { Yes, No }

function f(n: i32): string {
    return match (n) {
        Answer.Yes => "yes",   // error[E035]: match on non-enum value `i32` only accepts literal patterns, a binding name, or `_`
        _ => "no",
    };
}

function g(s: string): i32 {
    return match (s) {
        42 => 1,         // error[E035]: literal pattern of type i32 does not match scrutinee type string
        _ => 0,
    };
}
```

## Fix

Align the patterns with the scrutinee type.

```
function f(n: i32): string {
    return match (n) {
        0 => "zero",
        _ => "other",
    };
}
```
