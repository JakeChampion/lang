# E100 — a value that cannot cross a worker boundary

A `send` parameter is a worker boundary. Its argument is copied into another
worker's heap, so the argument must be send-safe: a scalar, a string, or a
struct, enum, array, tuple or map of send-safe values. A closure written at
the call crosses with its captures, so each captured variable and the
closure's result must be send-safe too.

None of these can cross. Two owners share a `Cell` by its address. A
function value carries its environment. A `dyn` value hides its concrete
type.

A view borrows another value's storage. A handle owns a descriptor. A
`@must_consume` value carries an obligation, and a copy makes two of it.

```
import "std/worker";

function main(): i32 {
    let shared: Cell[i32] = cell_new(1);
    // error[E100]: closure passed to `send` parameter "body" captures "shared" of type Cell[i32], which cannot cross a worker boundary: a Cell is shared by aliasing
    let w = worker.spawn((): i32 => shared.get());
    return w.join();
}
```

Fix: read the value before the closure and capture the result, or make the
worker return what the other side needs. A closure held in a variable cannot
be passed at all. Write it at the call. The rule is in `docs/WORKERS.md`.
