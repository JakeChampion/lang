# deadcode allowlist
# ===================
# Unreachable functions that the deadcode gate (tools/deadcode_gate.sh)
# is allowed to ignore. Keys are "<pkg-dir>:<func-name>". Keep this list
# SMALL — the default is to delete dead code, not allowlist it. Every
# entry needs a reason. New unreachable functions that aren't listed
# here fail CI.

# Builtin variant is dispatched through the Value interface; deleting it
# removes Builtin from the interface's method set.
